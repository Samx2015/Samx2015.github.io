What is it?

The meaningful features, in one menu-bar app.

  • Blackout Built-in Display One click mirrors the built-in display to an external one and blacks it out — with quick Displays and Notifications buttons, including guidance so notifications stay visible while mirroring.
  • Display controls Switch mirroring, dim displays until key press, sleep, shut down, or restart with confirmation, and adjust display brightness or contrast from the menu bar.
  • Custom display modes Install curated or custom HiDPI display modes, then switch supported resolutions from the menu.
  • Window arrangement Move the focused window to halves, corners, center positions, full screen-sized layouts, or another display/desktop with global shortcuts.
  • Arranged-window focus Bring windows back by layout position, cycle through windows in the same position, and assign shortcuts for specific apps.
  • Active Window Highlight Draw a click-through border around the focused normal app window, with configurable color, width, opacity, glow, and rounded corners.
  • Keyboard backlight Adjust the built-in MacBook keyboard brightness with a slider.
  • Auto Wi-Fi Switch When enabled, watches saved Wi-Fi networks and switches to a better known access point when your current signal drops.
  • Finder context menus Use New File, New Folder, Paste, Move Here, Copy Path, and Open in TextEdit, Terminal, Codex, Claude, VSCode, or another compatible app from Finder.
  • Safes and archives Encrypt selected files or folders into a local .safe file, add to an existing file, decrypt only selected contents, or work with supported .7z, .zip, and .dmg formats.
  • Pointer & Mouse Adjust pointer sensitivity and acceleration per mouse, including devices routed through tools such as Karabiner.
  • Scrolling Set scroll speed and acceleration per pointing device, including a linear mode that disables acceleration — with LinearMouse-compatible scaling.
  • Key & Button Remapping Create rules that send a key or shortcut, dual-role keys (tap for one action, hold for a modifier), or a Hyper key — recorded right in the dialog.
  • Audio Mixer Set per-app volume from the menu — boost a quiet app up to 200% — and mute apps individually. Requires the macOS System Audio Recording permission (macOS 14.4 or later); audio is processed locally.
  • Rectangle conflict helper Detects Rectangle or Rectangle Pro when running and offers a focused way to avoid overlapping window shortcut behavior.
  • 100% confidential Unlike Google Drive, OneDrive, GitHub, and other general-purpose cloud or code services, plaintext, passwords, and encryption keys stay on your Mac.
  • Privacy basics No account, no analytics, no Wi-Fi passwords, no Safe password logging, no Dock window, and clear guidance for optional Accessibility, Input Monitoring, System Audio Recording, Location, and Full Disk Access permissions.
