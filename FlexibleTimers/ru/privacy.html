Flexible Timers управляется Xintech LLC. Flexible Timers использует учетную запись информация для предоставления таймера, напоминания, учетной записи, синхронизации, отчета, и функции сообщений. Flexible Timers в настоящее время отправляет отчеты по электронной почте и сообщения электронной почты только на адрес электронной почты собственной учетной записи вошедшего в систему пользователя. В этой политике также описаны условия конфиденциальности SMS для телефона учетной записи. проверка и созданные пользователем напоминания SMS, отправляемые только самому пользователю проверенный номер телефона, включенный в учетную запись.

Информация, собираемая для электронной почты

Когда вошедший в систему пользователь запрашивает подтверждение, отчет, отзыв или напоминание по электронной почте, Flexible Timers может обрабатывать электронную почту учетной записи пользователя адрес, содержимое сообщения, данные таймера/отчета, необходимые для запроса, и метаданные доставки, необходимые для работы, устранения неполадок и обеспечения безопасности службы.

Информация, собранная для SMS

Когда вошедший в систему пользователь добавляет номер телефона своей учетной записи для SMS, Flexible Timers может хранить номер телефона, статус согласия, согласие источник, текстовая версия согласия, формулировка согласия, URL-адрес Условий SMS, Конфиденциальность URL-адрес политики, временная метка, статус проверки, созданное пользователем сообщение-напоминание. контент, запланированное время напоминаний и метаданные доставки сообщений, необходимые для эксплуатировать и проверять программу SMS.

Как используется информация SMS

Информация SMS используется для проверки номера телефона собственной учетной записи пользователя, отправить напоминание SMS, которое пользователь планирует для себя, сохранить согласие и записи об отказе, предотвращать злоупотребления, устранять неполадки при доставке и соблюдать перевозчика и юридические требования.

Никакой маркетинговой продажи или обмена

Flexible Timers не продает данные подписки SMS. Flexible Timers нет передавать данные о подписке SMS, номера телефонов или согласие на отправку текстовых сообщений третьим лицам. сторонам или филиалам в маркетинговых или рекламных целях.

Поставщики услуг

Flexible Timers может использовать поставщиков услуг, включая поставщиков SMS, для доставлять проверочные сообщения, доставлять запланированные пользователем напоминания SMS и управлять услугой. Эти поставщики могут обрабатывать информацию SMS только в том случае, если необходимо для предоставления услуги обмена сообщениями.

Уклоняться

Пользователи могут ответить STOP, чтобы отказаться от сообщений SMS. Пользователи могут ответить HELP на помогите.
