Polityka prywatności

Data wejścia w życie: 6 lipca 2026.

DeskHelper to lokalne narzędzie służące do wyświetlania paska menu macOS elementy sterujące, akcje menu kontekstowego Finder i lokalne szyfrowanie Safe.

  • Brak logowania DeskHelper, konta subskrypcji lub profilu użytkownika.
  • Brak śledzenia zdarzeń, śledzenia sesji, pikseli reklamowych i telemetrii użytkowania.
  • Działania displayowe, Finder, Safe i opinie działają lokalnie, chyba że zdecydujesz się wysłać pomoc e-mailową.

Zbieranie danych

DeskHelper nie gromadzi, nie przechowuje, nie sprzedaje, nie udostępnia ani nie przekazuje danych osobowych informacje poprzez zarządzanie wyświetlaniem, akcję Finder lub Safe funkcje szyfrowania. Xintech LLC nie otrzymuje informacji nt wyświetlaczy, plików, ustawień, sposobu użytkowania lub urządzenia z aplikacji, chyba że celowo wysyłasz je za pośrednictwem poczty e-mail.

  • Nie jest wymagane konto DeskHelper.
  • Nie uwzględniono żadnych narzędzi analitycznych, śledzących SDK, reklamowych SDK ani zestawów SDK do raportowania awarii.
  • Żadne dane telemetryczne w tle nie są wysyłane do Xintech LLC.

Dane lokalne

DeskHelper może przechowywać niewielką ilość danych o lokalnych preferencjach i ograniczone lokalne dzienniki diagnostyczne na komputerze Mac. Służy do tworzenia aplikacja zachowuje się spójnie pomiędzy uruchomieniami i przygotowuje raport o błędach wersje robocze, jeśli zdecydujesz się zgłosić błąd.

Lokalne preferencje mogą obejmować:

  • Ustawienia menu, takie jak automatyczne wygaszanie, tworzenie kopii lustrzanych, regulacja wyświetlania, skróty klawiaturowe i preferencje rozpoczynania po zalogowaniu.
  • Preferencje menu kontekstowego Finder, w tym włączone akcje i wybrany edytor, terminal lub kompatybilna aplikacja.
  • Zakładki dostępu do folderów, preferencje przepływu pracy Safe i ograniczone lokalne komunikaty diagnostyczne. DeskHelper nigdy nie przechowuje haseł Safe.

DeskHelper używa interfejsów API wyświetlania macOS do sterowania wyświetlaniem, a macOS Interfejsy API rozszerzenia Finder dla akcji menu kontekstowego Finder. Finder i Operacje Safe odczytują zaznaczenia lokalne tylko wtedy, gdy wybierzesz a DeskHelper akcja, a DeskHelper nie przesyła ścieżek Finder, zawartość pliku, zawartość Safe lub hasła Safe do Xintech LLC.

Rozmieszczanie i wyróżnianie okien

DeskHelper rozmieszcza też okna, oferuje globalne skróty klawiszowe i może wyróżniać aktywne okno. Używa do tego uprawnienia Dostępności w macOS; funkcje te działają tylko na lokalnych oknach po ich włączeniu lub uruchomieniu, a żadne dane okien nie opuszczają Twojego Maca.

Aktywność sieciowa

Normalne elementy sterujące wyświetlaczem DeskHelper, menu kontekstowe Finder i Safe funkcje szyfrowania nie wymagają połączenia sieciowego. Aktualizacje są obsługiwane przez Mac App Store.

Elementy menu Opinia otwierają wersję roboczą w domyślnej aplikacji e-mail. Aplikacja nie wysyła wiadomości e-mail automatycznie i nic nie jest wysyłane, chyba że Ty wybierz opcję Wyślij.

Raporty o błędach, prośby o funkcje i opinie

Opcje „Zgłoś błąd…”, „Zaproponuj funkcję…” i „Prześlij opinię…” pozycje menu otwierają wersję roboczą w domyślnej aplikacji e-mail, do której jest adresowany Xintech LLC. Aplikacja nie wysyła wiadomości e-mail automatycznie. Możesz przejrzyj, edytuj lub usuń wersję roboczą przed jej wysłaniem.

Wersja robocza może zawierać krótkie podsumowanie diagnostyczne, tak aby dział wsparcia mógł to zrobić zrozumieć kontekst: wersja aplikacji, wersja macOS, procesor architektura, stan wyświetlania, stan rozszerzenia Finder, włączone działania i bieżący stan aplikacji. Twój adres e-mail jest widoczny dla Xintech LLC tylko jeśli wyślesz e-mail.

Wersje robocze raportów o błędach mogą zawierać ograniczony fragment najnowszych raportów DeskHelper dzienniki diagnostyczne. Prośba o dodanie funkcji i ogólna opinia wersje robocze nie zawierają logów.

Diagnostyka i dzienniki

DeskHelper zapisuje komunikaty diagnostyczne do lokalnego urządzenia Apple system rejestrowania i prowadzi mały, ograniczony, lokalny dziennik diagnostyczny aplikacji. Te dzienniki są przechowywane lokalnie na Twoim Mac. Wybierając opcję „Zgłoś błąd…” może zebrać ograniczony fragment zawierający tylko DeskHelper z aplikacji lokalnej log i wstaw go do wersji roboczej wiadomości e-mail.

Nic nie zostanie wysłane, chyba że wybierzesz opcję Wyślij i możesz usunąć plik podsumowanie diagnostyczne lub fragment dziennika przed wysłaniem raportów o błędach.

Twoje wybory

  • Możesz pozostawić wersje robocze opinii jako niewysłane, edytować je lub usunąć szczegóły diagnostyczne.
  • Możesz włączyć lub wyłączyć rozszerzenie Finder w ustawieniach macOS.
  • Możesz usunąć lokalne preferencje aplikacji i zatwierdzenia folderów, korzystając ze zwykłych narzędzi do zarządzania preferencjami macOS.
