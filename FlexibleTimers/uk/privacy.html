Сервіс Flexible Timers керується Xintech LLC. Flexible Timers використовує інформацію облікового запису для надання функцій таймерів, нагадувань, облікового запису, синхронізації, звітів і повідомлень. Наразі Flexible Timers надсилає звіти та повідомлення електронною поштою лише на адресу електронної пошти облікового запису самого користувача, який увійшов у систему. Ця політика також описує умови конфіденційності для SMS, що використовуються для перевірки номера телефону облікового запису та створених користувачем SMS-нагадувань, які надсилаються лише на власний підтверджений номер телефону облікового запису користувача, який погодився отримувати SMS.

Інформація, що збирається для електронної пошти

Коли користувач, який увійшов у систему, запитує підтвердження, звіт, відгук або нагадування електронною поштою, Flexible Timers може обробляти адресу електронної пошти облікового запису користувача, вміст повідомлення, дані таймера/звіту, необхідні для запиту, а також метадані доставки, потрібні для роботи, усунення несправностей і захисту сервісу.

Інформація, що збирається для SMS

Коли користувач, який увійшов у систему, додає для SMS власний номер телефону облікового запису, Flexible Timers може зберігати номер телефону, статус згоди, джерело згоди, версію тексту згоди, формулювання згоди, URL Умов SMS, URL Політики конфіденційності, позначку часу, статус перевірки, вміст створеного користувачем нагадування, запланований час нагадування та метадані доставки повідомлень, необхідні для роботи й аудиту SMS-програми.

Як використовується інформація SMS

Інформація SMS використовується для перевірки власного номера телефону облікового запису користувача, надсилання SMS-нагадувань, які користувач планує для себе, ведення записів про згоду та відмову, запобігання зловживанням, усунення проблем із доставкою, а також дотримання вимог операторів зв’язку й законодавства.

Без продажу або передавання для маркетингу

Flexible Timers не продає дані згоди на SMS. Flexible Timers не передає дані згоди на SMS, номери телефонів або згоду на текстові повідомлення третім сторонам чи афілійованим особам для маркетингових або рекламних цілей.

Постачальники послуг

Flexible Timers може використовувати постачальників послуг, зокрема постачальників SMS, для доставки повідомлень підтвердження, доставки запланованих користувачем SMS-нагадувань і роботи сервісу. Ці постачальники можуть обробляти інформацію SMS лише в обсязі, необхідному для надання послуги обміну повідомленнями.

Відмова від SMS

Користувачі можуть відповісти STOP, щоб відмовитися від SMS-повідомлень. Користувачі можуть відповісти HELP, щоб отримати допомогу.
