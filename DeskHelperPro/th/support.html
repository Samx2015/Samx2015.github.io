ฝ่ายสนับสนุน DeskHelper Pro

สำหรับการสนับสนุน คำถามด้านความเป็นส่วนตัว บั๊ก ใบอนุญาต หรือไอเดีย ส่งอีเมลถึง admin@xintechllc.com.

คุณยังใช้ รายงานบั๊ก แนะนำคุณสมบัติ หรือส่งข้อเสนอแนะในเมนูแอปได้ รายการเหล่านี้จะเปิดร่างอีเมลให้ตรวจสอบก่อนส่ง

เมื่อรายงานปัญหา

โปรดระบุ:

  • เกิดอะไรขึ้นและคาดหวังอะไร
  • เวอร์ชัน macOS และรุ่น Mac หากทราบ
  • หน้าจอ MacBook ถูกมิเรอร์หรือขยาย
  • เวอร์ชันและหมายเลขบิลด์ของ DeskHelper Pro
  • ขั้นตอนที่ทำให้เกิดปัญหาซ้ำ

ร่างรายงานบั๊กอาจมีบันทึกวินิจฉัยสั้น ๆ ลบสิ่งที่ไม่ต้องการส่งได้

เมนูบริบทของ Finder

DeskHelper Pro ใช้ส่วนขยาย Finder ที่มาพร้อมกัน macOS เป็นผู้ควบคุมว่าเปิดใช้หรือไม่ คุณเปิดสิทธิ์จากเมนู DeskHelper Pro หรือในการตั้งค่าระบบส่วนรายการเข้าสู่ระบบและส่วนขยายได้

  • หากเมนูบริบท Finder ไม่ปรากฏ ให้ตรวจสอบว่า DeskHelper Pro ทำงานจากโฟลเดอร์ Applications
  • เปิดเมนู DeskHelper Pro แล้วเลือกกำหนดค่าเมนูบริบท Finder
  • หากการทำงาน Finder เปิดหรือสร้างรายการไม่ได้ macOS อาจขอสิทธิ์เข้าถึงโฟลเดอร์
  • สำหรับตำแหน่ง macOS ที่ป้องกันไว้ ให้เปิดการตั้งค่า Full Disk Access จาก DeskHelper Pro แล้วเปิดใช้แอป

Safes และ Secure Pocket

ใช้เมนูบริบท Finder เพื่อเข้ารหัสไฟล์หรือโฟลเดอร์ในเครื่องเป็นไฟล์ .safe เพิ่มรายการลง Safe ที่มีอยู่ หรือถอดรหัส Safe กลับเป็นโฟลเดอร์ รหัสผ่านใช้เฉพาะการทำงานที่เริ่มและไม่ถูกเก็บโดย DeskHelper Pro

Secure Pocket เก็บโน้ตส่วนตัว คลิปบอร์ด และไฟล์ขนาดเล็กในตู้นิรภัยเข้ารหัสในเครื่อง DeskHelper Pro ไม่อัปโหลด ส่ง หรือบันทึกเนื้อหาหรือรหัสผ่าน

ใบอนุญาตและอัปเดต

  • DeskHelper Pro มีช่วงทดลอง 14 วัน
  • การเปิดใช้ใบอนุญาตใช้ Lemon Squeezy และเก็บคีย์ใน Keychain ของ Mac
  • ตรวจสอบอัปเดตผ่าน Sparkle เมื่อเปิดตรวจสอบอัตโนมัติหรือเลือกตรวจสอบอัปเดต

หมายเหตุ

  • DeskHelper Pro แสดงในแถบเมนู macOS และไม่มีไอคอน Dock
  • Auto Wi-Fi Switch อาจต้องใช้สิทธิ์ตำแหน่งเพราะ macOS ปกป้องชื่อเครือข่าย Wi-Fi
  • การควบคุมไฟคีย์บอร์ดขึ้นอยู่กับฮาร์ดแวร์ Mac
  • อ่าน นโยบายความเป็นส่วนตัวของ DeskHelper Pro เพื่อดูรายละเอียด
