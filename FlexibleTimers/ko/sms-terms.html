XTimers by Xintech LLC SMS 약관

이 번역은 편의를 위해 제공됩니다. 영어 버전이 권위 있는 버전입니다. English.

XTimers는 Xintech LLC에서 운영합니다. XTimers는 로그인한 사용자가 본인의 계정 전화번호로 추가하고 확인한 뒤 수신 동의한 전화번호로만 SMS 메시지를 보낼 수 있습니다. 현재 SMS 프로그램은 계정 전화번호 인증 코드와 사용자가 직접 예약한 타이머/알림 SMS로 제한됩니다. XTimers는 마케팅 문자 메시지를 보내지 않으며, 사용자가 임의의 제3자 수신자에게 SMS를 보내도록 허용하지 않습니다. XTimers SMS는 양방향 채팅 또는 대화 서비스가 아니며, 수신 키워드는 STOP, HELP, START 및 YES 규정 준수 처리에만 사용됩니다.

수신 동의

사용자는 XTimers 앱에서 전화번호를 입력하고 미리 선택되어 있지 않은 체크박스를 명시적으로 선택하여 수신 동의합니다. 체크박스 문구는 다음과 같습니다. "이 전화번호로 내가 직접 예약하는 Flexible Timers by Xintech LLC의 SMS 인증 코드와 알림 메시지를 받는 데 동의합니다." 수신 동의 화면에는 이 SMS 약관, 개인정보 보호정책, 표준 메시지 및 데이터 요금 고지, STOP 및 HELP 지침, 메시지 빈도 정보, 마케팅 문자를 보내지 않는다는 안내도 표시됩니다. 동의는 구매 조건이 아닙니다. 다음의 동의 증거 페이지를 참조하십시오. xintechllc.com/FlexibleTimers/ko/sms-opt-in.html.

메시지 빈도

메시지 빈도는 달라질 수 있습니다. XTimers는 사용자가 본인의 계정 전화번호 확인을 요청할 때 확인 메시지를 보냅니다. Flexible Timers는 확인된 계정 소유자가 본인을 위해 SMS 알림을 만들고 예약한 경우에만 SMS 알림을 보냅니다. 사용자는 SMS로 XTimers에 채팅 답장이나 사용자가 작성한 메시지를 보낼 수 없습니다.

수수료

표준 메시지 및 데이터 요금이 적용될 수 있습니다. 메시지 및 데이터 요금은 이동통신사가 청구하며 귀하의 책임입니다.

옵트아웃

XTimers의 SMS 메시지를 수신 거부하려면 STOP에 회신하세요. STOP을 보낸 후에는 다시 수신 동의하지 않는 한 XTimers가 해당 전화번호로 SMS 메시지를 보내지 않습니다.

도움말

도움이 필요하면 HELP에 회신하세요. XTimers 지원팀에 문의할 수도 있습니다. xintechllc.com/FlexibleTimers/ko/support.html.

SMS 키워드 및 응답

STOP은 XTimers SMS에서 해당 전화번호를 수신 거부 처리합니다. 예상 STOP 응답은 다음과 같습니다. "XTimers SMS 수신을 거부했습니다. 더 이상 메시지가 전송되지 않습니다. 다시 수신하려면 START에 회신하세요."

HELP는 지원 정보를 요청합니다. 예상 HELP 응답은 다음과 같습니다. "XTimers는 계정 확인 코드와 사용자가 직접 예약한 SMS 알림을 보냅니다. 도움말: https://xintechllc.com/FlexibleTimers/support.html. 수신을 거부하려면 STOP에 회신하세요."

START 또는 YES는 사용자가 해당 계정 전화번호에 대해 이미 앱에서 동의한 후, 이전에 수신 거부한 전화번호를 다시 수신 동의 처리합니다. 예상 START 응답은 다음과 같습니다. "XTimers SMS 메시지 수신에 다시 동의했습니다. 메시지 빈도는 달라질 수 있습니다. 수신을 거부하려면 STOP, 도움이 필요하면 HELP에 회신하세요."

통신사 책임

무선 통신사는 지연되거나 전달되지 않은 메시지에 대해 책임을 지지 않습니다.
