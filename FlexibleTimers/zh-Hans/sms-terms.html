Flexible Timers by Xintech LLC SMS 条款

此翻译仅供参考。原始英文版本为权威版本。 English

Flexible Timers 由 Xintech LLC 运营。Flexible Timers 只会向登录用户 添加、验证并选择作为自己账户电话号码的号码发送 SMS 消息。 目前的 SMS 计划仅包括账户电话验证码，以及用户为自己创建和 安排的计时器/提醒 SMS。Flexible Timers 不发送营销短信，也不允许 用户向任意第三方收件人发送 SMS。Flexible Timers SMS 不是双向 聊天或对话服务；入站关键词仅用于 STOP、HELP、START 和 YES 合规处理。

选择接收

用户在 Flexible Timers 应用中输入电话号码，并主动选中默认未勾选的 复选框，即表示选择加入。复选框文字为：“我同意接收来自 Flexible Timers by Xintech LLC 的 SMS 验证码，以及我在此电话号码上 为自己安排的提醒消息。”选择加入屏幕还会显示这些 SMS 条款、 隐私政策、标准消息和数据费率说明、STOP 和 HELP 说明、消息频率 信息以及非营销说明。同意不是购买条件。 请参阅选择加入证据页面： xintechllc.com/FlexibleTimers/sms-opt-in.html.

消息频率

消息频率各不相同。用户请求验证自己的账户电话号码时，Flexible Timers 会发送验证消息。只有经过验证的账户所有者创建并为自己安排 SMS 提醒时，Flexible Timers 才会发送提醒。用户不能通过 SMS 发送 聊天回复，也不能通过 SMS 向 Flexible Timers 发送自定义消息。

费用

可能适用标准消息和数据费率。相关费用由您的移动运营商收取， 并由您承担。

退订

回复 STOP 可退订 Flexible Timers 的 SMS 消息。发送 STOP 后，Flexible Timers 将停止向该电话号码发送 SMS 消息，除非你再次选择接收。

帮助

回复 HELP 获取帮助。你也可以通过以下方式联系 Flexible Timers 支持： xintechllc.com/FlexibleTimers/zh-Hans/support.html.

SMS 关键词和回复

STOP 会让该电话号码退订 Flexible Timers SMS。预期的 STOP 回复为：“你已退订 Flexible Timers SMS。不会再发送消息。回复 START 可再次选择接收。”

HELP 用于请求支持信息。预期的 HELP 回复为：“Flexible Timers 会发送账户验证码以及你为自己安排的提醒 SMS。帮助：https://xintechllc.com/FlexibleTimers/zh-Hans/support.html。回复 STOP 退订。”

用户已在 App 中为该账户电话号码提供授权后，回复 START 或 YES 可让先前退订的电话号码重新选择接收。预期的 START 回复为：“你已重新选择接收 Flexible Timers SMS 消息。消息频率不固定。回复 STOP 退订，回复 HELP 获取帮助。”

运营商责任

无线运营商对延迟或未送达的消息不承担任何责任。

隐私

请参阅 Flexible Timers 隐私政策： xintechllc.com/FlexibleTimers/privacy.html.
