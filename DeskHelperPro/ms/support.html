Sokongan DeskHelper Pro

Untuk sokongan, soalan privasi, pepijat, lesen atau idea, e-mel kepada admin@xintechllc.com.

Anda juga boleh menggunakan Laporkan Pepijat, Cadangkan Ciri atau Hantar Maklum Balas dalam menu aplikasi. Item ini membuka draf e-mel untuk disemak sebelum dihantar.

Semasa melaporkan isu

Sertakan:

  • Apa yang berlaku dan apa yang anda jangkakan.
  • Versi macOS dan model Mac jika diketahui.
  • Sama ada skrin MacBook dicerminkan atau dilanjutkan.
  • Versi dan nombor binaan DeskHelper Pro.
  • Langkah untuk menghasilkan semula isu.

Draf laporan pepijat mungkin mengandungi nota diagnostik ringkas. Padam perkara yang tidak mahu dihantar.

Menu konteks Finder

DeskHelper Pro menggunakan sambungan Finder terbina. macOS mengawal sama ada sambungan itu diaktifkan. Anda boleh membuka kebenaran daripada menu DeskHelper Pro atau Tetapan Sistem di Item Log Masuk dan Sambungan.

  • Jika menu konteks Finder tidak muncul, pastikan DeskHelper Pro berjalan dari Applications.
  • Buka menu DeskHelper Pro dan pilih konfigurasi menu konteks Finder.
  • Jika tindakan Finder tidak boleh membuka atau mencipta item, macOS mungkin meminta akses folder.
  • Untuk lokasi macOS yang dilindungi, buka Full Disk Access daripada DeskHelper Pro dan aktifkan aplikasi.

Safes

Gunakan menu konteks Finder untuk menyulitkan fail atau folder tempatan terpilih menjadi fail .safe, menambah item ke Safe sedia ada atau menyahsulit Safe ke folder. Kata laluan hanya digunakan untuk tindakan yang dimulakan dan tidak disimpan oleh DeskHelper Pro.

Lesen dan kemas kini

  • DeskHelper Pro termasuk percubaan 14 hari.
  • Pengaktifan lesen menggunakan Lemon Squeezy dan menyimpan kunci dalam Keychain Mac.
  • Kemas kini diperiksa melalui Sparkle apabila pemeriksaan automatik dihidupkan atau apabila anda memilih Semak Kemas Kini.

Nota

  • DeskHelper Pro muncul dalam bar menu macOS dan tidak menunjukkan ikon Dock.
  • Auto Wi-Fi Switch mungkin memerlukan kebenaran Lokasi kerana macOS melindungi nama rangkaian Wi-Fi.
  • Kawalan lampu papan kekunci bergantung pada sokongan perkakasan Mac.
  • Baca Dasar Privasi DeskHelper Pro untuk butiran.
