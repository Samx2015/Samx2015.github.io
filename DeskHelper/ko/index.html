Mac App Store의 메뉴 막대 유틸리티

DeskHelper

유용한 데스크 기능을 하나의 Mac 유틸리티로.

DeskHelper는 디스플레이 제어, 윈도우 정렬과 단축키, 활성 윈도우 하이라이트, Finder 동작, 로컬 파일 암호화를 하나의 집중된 메뉴 막대 앱에 담았습니다. 샌드박스에서 실행되며 Mac App Store를 통해 제공됩니다.

디스플레이 제어 윈도우 단축 동작 활성 윈도우 강조 Finder 동작 로컬 Safe 암호화 (.safe) 프라이버시 우선

디스플레이·윈도우 제어

시스템 설정, 서드파티 윈도우 도구, 디스플레이 메뉴를 오가지 않고 작업 화면을 관리하세요.

  • 외장 모니터로 미러링하는 동안 MacBook 내장 화면을 블랙아웃.
  • 미러링 전환, 키 입력 전까지 화면 어둡게, 잠자기, 재시동, 시스템 종료, 밝기·대비 조절.
  • HiDPI를 포함해 디스플레이가 지원하는 모드를 빠르게 전환합니다.
  • 윈도우를 절반, 모서리, 가운데, 전체 화면 배치, 다른 디스플레이나 데스크탑으로 이동.
  • 활성 윈도우를 클릭이 통과되는 사용자 지정 테두리로 하이라이트.
사용자화 HiDPI 해상도 프리셋은 DeskHelper Pro의 기능입니다. DeskHelper는 디스플레이가 이미 지원하는 모드 사이를 전환합니다.

전역 단축키

손은 키보드 위에: 마우스를 건드리지 않고 윈도우를 정렬하고 디스플레이 간에 옮기고 포커스를 전환하세요.

  • 어느 앱에서나 작동하는 사용자화 가능한 단축키로 활성 윈도우를 정렬합니다.
  • 활성 윈도우를 이전 또는 다음 디스플레이로 이동합니다.
  • 위치를 지정해 포커스를 이동 — 왼쪽 절반, 모서리 또는 4분면을 차례로.
  • 앱 포커스 단축키로 즐겨 쓰는 앱을 앞으로 가져옵니다.
  • 키 입력까지 어둡게 하기와 잠자기를 어디서나 실행합니다.
단축키는 충돌을 피하기 위해 보조 키를 2개 이상 사용하며 언제든 기본값으로 재설정할 수 있습니다.

Finder 동작과 로컬 금고

선택한 파일, 암호, 암호화된 금고를 Mac 안에 두면서 Finder를 더 유용하게.

  • Finder에서 바로 새 파일과 폴더 만들기.
  • 붙여넣기, 이동, 경로 복사, 그리고 Terminal, TextEdit, VS Code, Codex, Claude 등 지원 앱에서 폴더 열기.
  • 선택한 파일이나 폴더를 로컬 .safe 파일로 암호화.
  • 기존 금고에 파일 추가 또는 선택한 항목만 복호화.
  • 호환 형식 .7z, .zip, .dmg는 DeskHelper Pro에서 사용할 수 있습니다.
  • 메뉴 제목에 대상 폴더를 표시할 수 있어 모든 동작이 예상한 위치에 적용됩니다.
Finder·금고 동작은 우클릭 메뉴에서 DeskHelper 동작을 선택할 때만 실행됩니다.

프라이버시 우선

DeskHelper는 로컬 Mac 워크플로를 위해 만들어졌습니다. 데스크 유틸리티를 또 하나의 계정, 분석 스트림, 클라우드 파일 서비스로 만들지 않습니다.

  • 샌드박스에서 실행되는 Mac App Store 앱.
  • 계정이 필요 없습니다.
  • 분석, 광고 SDK, 사용 원격 측정, 세션 추적이 없습니다.
  • Safe 암호는 저장·기록·전송되지 않으며 암호화는 로컬에서 실행됩니다.
  • 선택 권한은 단 두 가지로, 앱에서 실시간 상태와 함께 설명됩니다: 손쉬운 사용과 Finder 확장 프로그램.
What's good about it?

Less fuss at your desk.

  • Only blacks out when it should dark when mirrored, normal when the MacBook screen is part of your workspace
  • Fast everyday actions switch mirroring, dim until key press, sleep, arrange windows, highlight the active window, open Finder paths, and encrypt Safes
  • Helpful, not noisy runs from the menu bar without a Dock window, account, or analytics
For desk setups made for MacBooks that spend real time connected to an external display
For window speed global shortcuts handle layout, display moves, arranged-window focus, and app focus
For Finder and private files create, paste, move, open, encrypt, and decrypt selected items from the context menu you already use
For privacy no account, no analytics, no Safe password logging, and feedback opens as a reviewable email draft
How to get it

Install it from the Mac App Store.

  2. 2 DeskHelper를 설치하고 응용 프로그램에서 실행합니다.
  3. 3 해당 기능을 사용할 때만 Finder 확장 프로그램을 켜고 손쉬운 사용 권한을 부여하세요.
