Assistance XHelpers Pro

Pour l’assistance, les questions de confidentialité, les bugs, les licences ou les idées, envoyez un e-mail à admin@xintechllc.com.

Vous pouvez aussi utiliser Signaler un bug, Proposer une fonctionnalité ou Envoyer un retour dans le menu de l’app. Ces actions ouvrent un brouillon d’e-mail que vous pouvez relire avant l’envoi.

Pour signaler un problème

Lorsque vous signalez un problème, veuillez inclure :

  • Ce qui s’est passé et ce que vous attendiez.
  • Votre version de macOS et le modèle de Mac, si vous les connaissez.
  • Si l’écran du MacBook était en miroir ou étendu.
  • La version et le numéro de build de XHelpers Pro.
  • Les étapes pour reproduire le problème.

Les brouillons de rapport de bug peuvent inclure une courte note de diagnostic. Supprimez tout ce que vous ne souhaitez pas envoyer.

Menus contextuels du Finder

XHelpers Pro utilise une extension Finder intégrée. macOS contrôle si cette extension est activée. Vous pouvez ouvrir le flux d’autorisation et de réglages depuis le menu XHelpers Pro, ou ouvrir Réglages Système et consulter Ouverture et extensions.

  • Si les menus contextuels du Finder n’apparaissent pas, vérifiez que XHelpers Pro s’exécute depuis Applications.
  • Ouvrez le menu XHelpers Pro et choisissez Configurer les menus contextuels du Finder.
  • Si une action Finder ne peut pas ouvrir ou créer un élément, macOS peut demander votre approbation pour l’accès au dossier.
  • Pour les emplacements macOS protégés, ouvrez les réglages Accès complet au disque depuis XHelpers Pro et activez l’app.

Safes

Utilisez les menus contextuels du Finder pour chiffrer les fichiers ou dossiers locaux sélectionnés dans un fichier .safe, ajouter des éléments à un Safe existant ou déchiffrer un Safe dans un dossier. Les mots de passe ne sont utilisés que pour l’action lancée et ne sont pas stockés par XHelpers Pro.

Licence et mises à jour

  • XHelpers Pro inclut un essai de 14 jours.
  • L’activation de licence utilise Lemon Squeezy et stocke la clé dans le trousseau de votre Mac.
  • Les mises à jour sont vérifiées avec Sparkle lorsque la vérification automatique est activée ou quand vous choisissez Rechercher des mises à jour.

Compte Xin et connexion

Le compte Xin est facultatif. Chaque outil local, la période d’essai de 14 jours et l’activation locale de Pro fonctionnent lorsque vous êtes déconnecté et lorsque ce Mac est hors ligne. Si les services de compte sont indisponibles, XHelpers Pro le signale dans la fenêtre de compte et le reste de l’app continue de fonctionner.

Ces cinq termes désignent des choses différentes et ne sont pas interchangeables :

  • Identité de connexion — l’identité e-mail, Google ou Apple avec laquelle vous vous authentifiez.
  • Compte Xin — le compte Xintech qui contient vos adhésions aux produits.
  • Adhésion XHelpers — l’inscription de ce compte à XHelpers.
  • Activation locale — la clé de licence activée sur ce Mac ; c’est elle qui déverrouille les fonctions Pro locales.
  • Droits côté serveur — l’accès payant enregistré sur le serveur pour l’adhésion XHelpers.

Créer l’un ne crée jamais le suivant. Se connecter ne crée pas de compte Xin, un compte Xin n’inscrit pas XHelpers, et ni l’un ni l’autre n’active de licence sur ce Mac.

Chaque méthode de connexion se récupère différemment :

  • Inscription par mot de passe — confirmez l’adresse à partir de l’e-mail de confirmation avant de vous connecter, et utilisez Renvoyer le code s’il n’est pas arrivé.
  • Récupération de mot de passe — demandez un message de récupération, ouvrez-le sur ce Mac, puis définissez un nouveau mot de passe dans la fenêtre qui s’ouvre. Demander une récupération ne vous connecte pas.
  • Code de connexion — demandez un code et saisissez-le avant son expiration. Les codes sont à usage unique ; choisissez Renvoyer le code de connexion plutôt que de démarrer une autre connexion.
  • Google — terminez l’étape dans le navigateur et revenez à XHelpers Pro. Si vous l’annulez ou si le rappel échoue, relancez l’étape Google.
  • Apple — terminez l’étape dans le navigateur et revenez à XHelpers Pro. Si vous l’annulez ou si le rappel échoue, relancez l’étape Apple. Si vous avez choisi Hide My Email, les e-mails de compte vous parviennent via le relais d’Apple, et désactiver ce relais dans vos réglages d’identifiant Apple les interrompt.

Deux identités de fournisseur ne convergent d’elles-mêmes que lorsque le fournisseur confirme la même adresse e-mail vérifiée. Ajouter une identité Google ou Apple utilisant une autre adresse est une action de liaison explicite dans Gérer les méthodes de connexion.

Conservez au moins une méthode liée que vous pouvez encore utiliser. L’assistance ne peut ni réattribuer, ni fusionner, ni récupérer une identité, une adhésion, des droits ou une licence à partir d’une adresse e-mail, d’un nom affiché, d’une image de reçu ou de la connaissance d’une clé de licence.

Déconnexion et suppression

  • Se déconnecter — efface la session de ce Mac. Cette action ne supprime ni les données côté serveur, ni le compte Xin, ni l’activation locale.
  • Supprimer les données XHelpers — retire l’adhésion XHelpers, les droits côté serveur et les données XHelpers du serveur. Le compte Xin, les autres adhésions, l’identité de connexion, les fichiers locaux et l’activation locale demeurent.
  • Supprimer le compte Xin partout — retire toutes les adhésions aux produits affichées dans le compte, le compte Xin et l’identité de connexion, et efface la session de ce Mac. Elle ne révoque pas l’autorisation du côté d’Apple ; retirez XHelpers de Sign in with Apple dans vos réglages d’identifiant Apple si vous le souhaitez. Votre licence locale reste activée.
  • Supprimer l’identité de connexion — s’applique lorsque vous vous êtes connecté sans jamais créer de compte Xin.

Chaque suppression exige une nouvelle connexion avec une méthode liée et le texte de confirmation exact. Une fois acceptée, elle ne peut pas être annulée.

Si une suppression est interrompue par un problème réseau, une fermeture ou une déconnexion, rouvrez la fenêtre de compte et poursuivez-la. L’opération en attente reprend comme la même opération ; ne démarrez pas une seconde suppression.

L’assistance ne demande jamais de mot de passe, de code de connexion, de jeton, de justificatif de reprise ni d’exportation Keychain. Pour un problème de compte, envoyez l’identifiant d’opération affiché dans la fenêtre de compte et retirez tout le reste du brouillon.

Notes

  • XHelpers Pro apparaît dans la barre des menus de macOS et n’affiche pas d’icône dans le Dock.
  • Auto Wi-Fi Switch peut nécessiter l’autorisation Localisation car macOS protège les noms de réseaux Wi-Fi.
  • Le contrôle du rétroéclairage du clavier dépend de la prise en charge matérielle du Mac.
  • Lisez la politique de confidentialité de XHelpers Pro pour plus de détails.
