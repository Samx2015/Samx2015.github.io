Personvernerklæring for Flexible Timers by Xintech LLC

Denne oversettelsen er gitt for enkelhets skyld. Den engelske versjonen er den autoritative versjonen. English.

Flexible Timers drives av Xintech LLC. Flexible Timers bruker kontoinformasjon til å levere timer-, påminnelses-, konto-, synkroniserings-, rapport- og meldingsfunksjoner. Flexible Timers sender for tiden e-postrapporter og e-postmeldinger bare til e-postadressen for den innloggede brukerens egen konto. Denne erklæringen beskriver også SMS-personvernvilkårene for verifisering av kontotelefonnummer og brukeropprettede SMS-påminnelser som bare sendes til brukerens eget bekreftede og påmeldte kontotelefonnummer.

Informasjon samlet for e-post

Når en innlogget bruker ber om bekreftelse, en rapport, tilbakemelding eller en e-postpåminnelse, kan Flexible Timers behandle e-postadressen for brukerens konto, meldingsinnhold, timer-/rapportdata som trengs for forespørselen, og leveringsmetadata som trengs for å drifte, feilsøke og sikre tjenesten.

Informasjon samlet inn for SMS

Når en innlogget bruker legger til sitt eget kontotelefonnummer for SMS, kan Flexible Timers lagre telefonnummeret, samtykkestatus, samtykkekilde, samtykketekstversjon, samtykketekst, URL til SMS-vilkår, URL til personvernerklæring, tidsstempel, bekreftelsesstatus, innhold i brukeropprettede påminnelser, planlagt påminnelsestid og metadata for meldingslevering som trengs for å drifte og revidere SMS-programmet.

Hvordan SMS-informasjon brukes

SMS-informasjon brukes til å bekrefte brukerens eget kontotelefonnummer, sende SMS-påminnelser som brukeren planlegger for seg selv, vedlikeholde registreringer over påmelding og avmelding, forhindre misbruk, feilsøke levering og overholde krav fra mobiloperatører og lovkrav.

Ingen salg eller deling for markedsføring

Flexible Timers selger ikke SMS-påmeldingsdata. Flexible Timers deler ikke SMS-påmeldingsdata, telefonnumre eller samtykke til tekstmeldinger med tredjeparter eller tilknyttede selskaper for markedsførings- eller reklameformål.

Tjenesteleverandører

Flexible Timers kan bruke tjenesteleverandører, inkludert SMS-leverandører, til å levere bekreftelsesmeldinger, levere SMS-påminnelser planlagt av brukeren og drifte tjenesten. Disse leverandørene kan bare behandle SMS-informasjon i den grad det er nødvendig for å levere meldingstjenesten.

Avmelding

Brukere kan svare STOP for å melde seg av SMS-meldinger. Brukere kan svare HELP for å få hjelp.
