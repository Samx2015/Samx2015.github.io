XHelpers Pro 支持

如需支持、隐私问题、错误、许可证问题或想法，请发送邮件至 admin@xintechllc.com.

你也可以在 App 菜单中使用“报告问题”、“建议功能”或“发送反馈”。这些项目会打开邮件草稿，方便你在发送前检查所有内容。

报告问题时

报告问题时，请包含：

  • 发生了什么，以及你期望发生什么。
  • 你的 macOS 版本和 Mac 型号（如果知道）。
  • 涉及哪一类功能，例如显示器控制、窗口快捷键、Finder 操作、保险箱、指针设置、按键或按钮重新映射，或音频混音器。
  • MacBook 屏幕是镜像还是扩展。
  • 你最近是否授予、拒绝或更改过 XHelpers Pro 的 macOS 权限。
  • XHelpers Pro 版本和构建号。
  • 可复现问题的步骤。

错误报告草稿可能包含一小段诊断说明。请删除你不想发送的内容。

显示器、窗口、指针与输入

  • 显示器工具包括自动黑屏、镜像、按键前保持调暗、睡眠、亮度与对比度控制、键盘背光，以及在 macOS 和显示器支持时安装自定义 HiDPI 模式。
  • 窗口排列、聚焦已排列窗口、聚焦 App 的快捷键、移至其他显示器的操作和“活动窗口高亮”可能需要“辅助功能”权限，因为 macOS 会保护窗口控制操作。
  • 指针配置、滚动速度设置和按键或按钮重新映射均在这台 Mac 上本地运行；根据你启用的操作，可能需要“辅助功能”或“输入监控”权限。
  • 音频混音器需要 macOS 的“系统音频录制”权限。音频仅在本地处理，XHelpers Pro 不会录制、保存、上传或转写音频。
  • 如果快捷键不起作用，请检查它是否与 macOS、Rectangle 或 Rectangle Pro 等其他实用工具，或其他全局快捷键 App 冲突。

Finder 上下文菜单

XHelpers Pro 使用内置 Finder 扩展。macOS 控制该扩展是否启用。你可以从 XHelpers Pro 菜单打开权限和设置流程，或在系统设置的“登录项与扩展”中查看。

  • 如果 Finder 上下文菜单没有出现，请确认 XHelpers Pro 正在从“应用程序”运行。
  • 打开 XHelpers Pro 菜单并选择“配置 Finder 上下文菜单”。
  • 如果 Finder 操作无法打开或创建项目，macOS 可能需要你批准文件夹访问权限。
  • 对于受保护的 macOS 位置，请从 XHelpers Pro 打开“完全磁盘访问权限”设置并在那里启用 App。

保险箱与归档

使用 Finder 上下文菜单可将选中的本地文件或文件夹加密为 .safe 文件、将选中项目添加到现有文件，或将选中内容解密回文件夹。XHelpers Pro 还支持适用的 .7z、.zip 和 .dmg 归档操作。密码只用于你启动的操作，XHelpers Pro 不会保存密码。

Xin 账户与登录

Xin 账户是可选的。无需登录即可试用和激活许可。首次激活许可需要连接互联网，App 也会定期验证已保存的许可。如果账户服务不可用，XHelpers Pro 会在账户窗口中提示；账户登录与这台 Mac 上的许可激活始终相互独立。

以下五个术语含义各不相同，不能互换：

  • 登录身份——你用来进行身份验证的电子邮件、Google 或 Apple 身份。
  • Xin 账户——持有你各项产品会员资格的 Xintech 账户。
  • XHelpers 会员资格——该账户在 XHelpers 中的登记。
  • 本地激活——在这台 Mac 上激活的许可证密钥；本地 Pro 功能由它解锁。
  • 服务器权益——服务器上为该 XHelpers 会员资格记录的付费访问权限。

创建其中一项绝不会创建下一项。登录不会创建 Xin 账户，Xin 账户不会登记 XHelpers，两者都不会在这台 Mac 上激活许可证。

每种登录方式的恢复方法各不相同：

  • 密码注册——先通过确认邮件确认该地址，然后再登录；如果邮件未送达，请使用“重新发送验证码”。
  • 密码恢复——请求一封恢复邮件，在这台 Mac 上打开它，然后在打开的窗口中设置新密码。请求恢复不会让你登录。
  • 登录验证码——请求验证码并在其过期前输入。验证码只能使用一次；请选择“重新发送登录验证码”，而不要改用另一种登录方式重新开始。
  • Google——完成浏览器中的步骤并返回 XHelpers Pro。如果你取消该步骤或回调失败，请重新开始 Google 登录步骤。
  • Apple——完成浏览器中的步骤并返回 XHelpers Pro。如果你取消该步骤或回调失败，请重新开始 Apple 登录步骤。如果你选择了 Hide My Email，账户电子邮件会通过 Apple 的转发服务送达你；在 Apple ID 设置中关闭该转发会使其停止送达。

只有当服务商确认为同一个已验证的电子邮件地址时，两个服务商身份才会自行归并。添加使用不同地址的 Google 或 Apple 身份，是在“管理登录方式”中执行的明确关联操作。

请至少保留一种你仍能使用的已关联登录方式。支持团队无法仅凭电子邮件地址、显示名称、收据图片或对某个许可证密钥的知悉，来重新指派、合并或恢复身份、会员资格、权益或许可证。

退出登录与删除

  • 退出登录会清除这台 Mac 上的会话。它不会删除服务器数据、Xin 账户或本地激活。
  • 删除 XHelpers 数据会移除 XHelpers 会员资格、服务器权益和 XHelpers 服务器数据。Xin 账户、其他会员资格、登录身份、本地文件和本地激活会保留。
  • 从所有位置删除 Xin 账户会移除账户中显示的每一项产品会员资格、Xin 账户和登录身份，并清除这台 Mac 上的会话。它不会撤销 Apple 一侧的授权；如果你希望这样做，请在 Apple ID 设置的 Sign in with Apple 中移除 XHelpers。你的本地许可证仍保持激活。
  • 删除登录身份适用于你已登录但从未创建 Xin 账户的情况。

每种删除都需要使用一种已关联的方式重新登录，并输入准确的确认文本。一经受理即无法撤销。

如果删除因网络问题、退出 App 或退出登录而中断，请重新打开账户窗口并继续。待处理的操作会作为同一操作继续进行；请勿开始第二次删除。

支持团队绝不会索取密码、登录验证码、令牌、续行凭据或钥匙串（Keychain）导出内容。如遇账户问题，请发送账户窗口中显示的操作标识符，并从草稿中删除其他所有内容。

说明

  • XHelpers Pro 显示在 macOS 菜单栏中，不显示 Dock 图标。
  • Auto Wi-Fi Switch 可能需要位置权限，因为 macOS 会保护 Wi-Fi 网络名称。
  • 键盘背光控制取决于 Mac 硬件支持。
  • 部分显示模式、指针属性和音频控制取决于 macOS 版本、Mac 硬件和已连接设备。
  • 阅读 XHelpers Pro 隐私政策 了解详情。
