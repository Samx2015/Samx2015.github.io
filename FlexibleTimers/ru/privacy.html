Политика конфиденциальности Flexible Timers by Xintech LLC

Этот перевод предоставлен для удобства. Английская версия является авторитетной версией. English.

Сервис Flexible Timers управляется Xintech LLC. Flexible Timers использует информацию учетной записи для предоставления функций таймеров, напоминаний, учетной записи, синхронизации, отчетов и сообщений. В настоящее время Flexible Timers отправляет отчеты и сообщения по электронной почте только на адрес электронной почты учетной записи самого вошедшего в систему пользователя. В этой политике также описаны условия конфиденциальности для SMS, используемых для проверки номера телефона учетной записи и для созданных пользователем SMS-напоминаний, которые отправляются только на собственный подтвержденный номер телефона учетной записи пользователя, выбравшего получение SMS.

Информация, собираемая для электронной почты

Когда вошедший в систему пользователь запрашивает подтверждение, отчет, обратную связь или напоминание по электронной почте, Flexible Timers может обрабатывать адрес электронной почты учетной записи пользователя, содержимое сообщения, данные таймера/отчета, необходимые для запроса, и метаданные доставки, необходимые для работы, устранения неполадок и защиты сервиса.

Информация, собираемая для SMS

Когда вошедший в систему пользователь добавляет для SMS собственный номер телефона учетной записи, Flexible Timers может хранить номер телефона, статус согласия, источник согласия, версию текста согласия, формулировку согласия, URL Условий SMS, URL Политики конфиденциальности, отметку времени, статус проверки, содержание созданного пользователем напоминания, запланированное время напоминания и метаданные доставки сообщений, необходимые для работы и проверки SMS-программы.

Как используется информация SMS

Информация SMS используется для проверки собственного номера телефона учетной записи пользователя, отправки SMS-напоминаний, которые пользователь планирует для себя, ведения записей о согласии и отказе, предотвращения злоупотреблений, устранения проблем с доставкой, а также соблюдения требований операторов связи и закона.

Без продажи или передачи для маркетинга

Flexible Timers не продает данные согласия на SMS. Flexible Timers не передает данные согласия на SMS, номера телефонов или согласие на текстовые сообщения третьим лицам или аффилированным лицам для маркетинговых или рекламных целей.

Поставщики услуг

Flexible Timers может использовать поставщиков услуг, включая поставщиков SMS, для доставки проверочных сообщений, доставки запланированных пользователем SMS-напоминаний и работы сервиса. Эти поставщики могут обрабатывать информацию SMS только в объеме, необходимом для предоставления услуги обмена сообщениями.

Отказ от SMS

Пользователи могут ответить STOP, чтобы отказаться от SMS-сообщений. Пользователи могут ответить HELP, чтобы получить помощь.
