XTimers by Xintech LLC SMS Opt-In Evidence

This page documents the XTimers SMS opt-in flow for Twilio toll-free verification. XTimers is operated by Xintech LLC. The end business shown to users is XTimers by Xintech LLC. Flexible Timers SMS is limited to account phone verification codes and user-created timer/reminder SMS sent only to a signed-in user's own verified, opted-in account phone number. XTimers does not let users message arbitrary third parties, does not send marketing text messages, and does not provide two-way SMS chat.

Opt-In Flow

  1. User signs in to XTimers.
  2. User opens Account Info.
  3. User opens Set Up SMS.
  4. User enters their own phone number.
  5. The SMS consent checkbox is not pre-selected.
  6. User affirmatively checks the SMS consent checkbox.
  7. User can open the SMS Terms and Privacy Policy links from the same screen.
  8. User clicks Continue to request a one-time verification code.
  9. After the phone is verified and opted in, the user may schedule reminder SMS only to that same verified, opted-in account phone number.

Consent Language

I agree to receive SMS verification codes and reminder messages I schedule for myself from XTimers by Xintech LLC at this phone number. Standard message and data rates may apply. Reply STOP to opt out and HELP for help. Message frequency varies. XTimers will not send marketing texts. Consent is not a condition of purchase.

Keyword Responses

Inbound keywords are used only for compliance and account-phone messaging controls. XTimers does not accept general SMS conversations.

STOP response: You are opted out of XTimers SMS. No more messages will be sent. Reply START to opt in again.

HELP response: XTimers sends account verification codes and reminder SMS you schedule for yourself. Help: https://xintechllc.com/FlexibleTimers/support.html. Reply STOP to opt out.

START response: You have opted back in to XTimers SMS messages. Message frequency varies. Reply STOP to opt out, HELP for help.
