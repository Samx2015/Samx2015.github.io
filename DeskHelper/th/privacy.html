นโยบายความเป็นส่วนตัว

วันที่มีผลบังคับใช้: 13 มิถุนายน 2569

DeskHelper เป็นยูทิลิตี้แถบเมนู macOS ตัวแรกในเครื่องสำหรับการแสดงผล การควบคุม การกระทำของเมนูบริบท Finder และการเข้ารหัส Safe ในเครื่อง

  • ไม่มีการลงชื่อเข้าใช้ DeskHelper บัญชีการสมัครสมาชิก หรือโปรไฟล์ผู้ใช้
  • ไม่มีการติดตามกิจกรรม การติดตามเซสชัน พิกเซลโฆษณา หรือการวัดและส่งข้อมูลทางไกลการใช้งาน
  • การดำเนินการจอแสดงผล ตัวค้นหา ปลอดภัย และคำติชมจะทำงานภายในเครื่อง เว้นแต่คุณจะเลือกส่งการสนับสนุนทางอีเมล

การรวบรวมข้อมูล

DeskHelper ไม่รวบรวม จัดเก็บ ขาย แบ่งปัน หรือส่งต่อส่วนบุคคล ข้อมูลผ่านการจัดการการแสดงผล การดำเนินการ Finder หรือ Safe คุณสมบัติการเข้ารหัส Xintech LLC ไม่ได้รับข้อมูลเกี่ยวกับ จอแสดงผล ไฟล์ การตั้งค่า การใช้งาน หรืออุปกรณ์ของคุณจากแอป เว้นแต่ คุณจงใจส่งมันผ่านการสนับสนุนทางอีเมล

  • ไม่จำเป็นต้องมีบัญชี DeskHelper
  • ไม่มีการวิเคราะห์ SDK การติดตาม SDK โฆษณา หรือ SDK การรายงานข้อขัดข้องรวมอยู่ด้วย
  • ไม่มีการส่งข้อมูลระยะไกลในเบื้องหลังไปยัง Xintech LLC

ข้อมูลท้องถิ่น

DeskHelper อาจจัดเก็บข้อมูลการตั้งค่าท้องถิ่นจำนวนเล็กน้อยและ บันทึกการวินิจฉัยภายในแบบมีขอบเขตบน Mac ของคุณ สิ่งนี้ใช้ในการทำ แอพทำงานสม่ำเสมอระหว่างการเปิดตัวและเพื่อเตรียมรายงานข้อผิดพลาด ฉบับร่างเมื่อคุณเลือกที่จะรายงานข้อบกพร่อง

การตั้งค่าท้องถิ่นอาจรวมถึง:

  • การตั้งค่าเมนู เช่น ปิดไฟอัตโนมัติ การมิเรอร์ การปรับการแสดงผล แป้นพิมพ์ลัด และการตั้งค่าเริ่มต้นเมื่อเข้าสู่ระบบ
  • การตั้งค่าเมนูบริบทของ Finder รวมถึงการดำเนินการที่เปิดใช้งาน และตัวแก้ไข เทอร์มินัล หรือแอพที่คุณเลือกไว้
  • บุ๊กมาร์กการเข้าถึงโฟลเดอร์ การตั้งค่าเวิร์กโฟลว์ที่ปลอดภัย และข้อความการวินิจฉัยภายในแบบมีขอบเขต DeskHelper ไม่เคยเก็บรหัสผ่านที่ปลอดภัย

DeskHelper ใช้ macOS API การแสดงผลสำหรับการควบคุมการแสดงผลและ macOS API ส่วนขยาย Finder สำหรับการดำเนินการเมนูบริบท Finder Finder และ การดำเนินการ Safe อ่านการเลือกในเครื่องเฉพาะเมื่อคุณเลือก การดำเนินการ DeskHelper และ DeskHelper ไม่ได้อัปโหลดเส้นทาง Finder เนื้อหาไฟล์ เนื้อหา Safe หรือรหัสผ่าน Safe ไปยัง Xintech LLC

กิจกรรมเครือข่าย

ส่วนควบคุมการแสดงผลปกติของ DeskHelper เมนูบริบทของ Finder และ Safe คุณสมบัติการเข้ารหัสไม่จำเป็นต้องมีการเชื่อมต่อเครือข่าย อัพเดทอยู่ครับ จัดการผ่าน Mac App Store

รายการเมนูคำติชมเปิดแบบร่างในแอปอีเมลเริ่มต้นของคุณ แอพ ไม่ส่งอีเมลโดยอัตโนมัติ และจะไม่มีการส่งอะไรเลยเว้นแต่คุณ เลือกส่ง

ร่างรายงานข้อผิดพลาดอาจมีข้อความที่ตัดตอนมาจากข้อมูลล่าสุด DeskHelper บันทึกการวินิจฉัย คำขอคุณลักษณะและข้อเสนอแนะทั่วไป ฉบับร่างไม่รวมบันทึก

การวินิจฉัยและบันทึก

DeskHelper เขียนข้อความวินิจฉัยไปยัง Apple แบบครบวงจรภายในเครื่อง ระบบบันทึกและเก็บบันทึกการวินิจฉัยภายในแอปที่มีขอบเขตขนาดเล็ก บันทึกเหล่านี้ถูกจัดเก็บไว้ใน Mac ของคุณ การเลือก "รายงานข้อผิดพลาด..." อาจรวบรวม DeskHelper-ข้อความที่ตัดตอนมาจาก app-local ที่มีขอบเขตเท่านั้น เข้าสู่ระบบและแทรกลงในร่างอีเมล

ไม่มีการส่งสิ่งใดเว้นแต่คุณจะเลือกส่ง และคุณสามารถลบได้ สรุปการวินิจฉัยหรือบันทึกที่ตัดตอนมาก่อนที่จะส่งรายงานข้อผิดพลาด
