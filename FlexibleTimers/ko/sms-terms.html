Flexible Timers는 Xintech LLC에 의해 운영됩니다. Flexible Timers는 SMS를 보낼 수 있습니다. 로그인한 사용자가 추가, 확인 및 확인한 전화번호로만 메시지를 보낼 수 있습니다. 자신의 계정 전화번호로 선택합니다. 현재 SMS 프로그램은 다음과 같습니다. 계정 전화 인증 코드 및 사용자가 만든 타이머/알림으로 제한됩니다. 사용자가 스스로 예약하는 SMS입니다. Flexible Timers가 보내지 않습니다 문자 메시지를 마케팅하고 사용자가 SMS를 임의의 사람에게 보내는 것을 허용하지 않습니다. 제3자 수신자. Flexible Timers SMS는 양방향 채팅이 아니거나 대화 서비스; 인바운드 키워드는 STOP, HELP, START에만 사용됩니다. 및 YES 규정 준수 처리.

선택

사용자는 전화번호를 입력하여 Flexible Timers 앱 내에서 옵트인합니다. 미리 선택되지 않은 상자를 긍정적으로 선택합니다. 체크박스 다음과 같이 말합니다. "SMS 인증 코드 및 알림 메시지를 받는 데 동의합니다. 내가 직접 예약한 Flexible Timers by Xintech LLC에서 전화번호." 옵트인 화면에는 이러한 SMS 약관도 표시됩니다. 개인 정보 보호 정책, 표준 메시지 및 데이터 속도 공개, STOP 및 HELP 지침, 메시지 빈도 정보 및 비마케팅 언어. 동의는 구매 조건이 아닙니다. 다음의 동의 증거 페이지를 참조하십시오. xintechllc.com/FlexibleTimers/ko/sms-opt-in.html.

메시지 빈도

메시지 빈도는 다양합니다. Flexible Timers는 다음과 같은 경우에 확인 메시지를 보냅니다. 사용자가 자신의 계정 전화번호 확인을 요청합니다. 유연한 타이머는 확인된 계정 소유자가 생성하고 SMS 알림을 스스로 예약합니다. 사용자는 채팅 답장을 보낼 수 없습니다. 또는 SMS가 Flexible Timers에 보내는 사용자 작성 메시지입니다.

수수료

표준 메시지 및 데이터 요금이 적용될 수 있습니다. 메시지 및 데이터 속도는 이동통신사에서 청구하며 이에 대한 책임은 귀하에게 있습니다.

옵트아웃

Flexible Timers의 SMS 메시지를 선택 해제하려면 STOP에 회신하세요. 보낸 후 STOP, Flexible Timers는 해당 전화번호로 SMS 메시지 전송을 중지합니다. 다시 선택하지 않는 한.

돕다

도움을 받으려면 HELP에 답장하세요. Flexible Timers 지원팀에 문의할 수도 있습니다. xintechllc.com/FlexibleTimers/ko/support.html.

SMS 키워드 및 응답

STOP는 Flexible Timers SMS에서 전화번호를 선택합니다. 예상되는 STOP 응답은 다음과 같습니다. "Flexible Timers SMS를 선택 해제했습니다. 더 이상 메시지가 없습니다. 전송됩니다. 다시 선택하려면 START에 답장을 보내세요."

HELP는 지원 정보를 요청합니다. 예상되는 HELP 응답은 다음과 같습니다. "Flexible Timers는 계정 확인 코드와 SMS 알림을 보냅니다. 스스로 일정을 잡으세요. 도움말: https://xintechllc.com/FlexibleTimers/support.html. 답장하다 STOP를 선택 해제하세요."

START 또는 YES는 이전에 선택 해제된 전화번호를 나중에 다시 선택합니다. 사용자가 이미 해당 계정 전화에 대한 앱 동의를 제공했습니다. 예상되는 START 응답은 다음과 같습니다 "Flexible Timers SMS 메시지 수신을 다시 선택하셨습니다. 메시지 빈도 다양합니다. 선택 해제하려면 STOP에 답장을 보내고, 도움을 받으려면 HELP에 답장하세요."
