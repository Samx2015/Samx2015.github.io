XHelpers Pro Support

For support, privacy questions, bugs, license questions, or ideas, email admin@xintechllc.com.

You can also use Report a Bug, Suggest a Feature, or Send Feedback in the app menu. These items open an email draft so you can review everything before sending it.

When Reporting an Issue

When reporting an issue, please include:

  • What happened and what you expected to happen.
  • Your macOS version and Mac model, if known.
  • Which feature area was involved, such as display controls, window shortcuts, Finder actions, Safes, pointer settings, key/button remapping, or Audio Mixer.
  • Whether the MacBook screen was mirrored or extended.
  • Whether you recently granted, denied, or changed a macOS permission for XHelpers Pro.
  • The XHelpers Pro version and build number.
  • The steps that reproduce the issue.

Bug report drafts may include a short diagnostic note. Remove anything you do not want to send.

Display, Windows, Pointer, and Input

  • Display tools include Auto Blackout, mirroring, dim-until-key-press, sleep, brightness/contrast controls, keyboard backlight, and custom HiDPI mode installation where supported by macOS and the display.
  • Window arrangement, arranged-window focus, app-focus shortcuts, move-to-display actions, and Active Window Highlight may require Accessibility permission because macOS protects window control.
  • Pointer profiles, scroll speed settings, and key/button remapping run locally on this Mac and may require Accessibility or Input Monitoring depending on the action you enable.
  • Audio Mixer requires macOS System Audio Recording permission. Audio is processed locally and is not recorded, saved, uploaded, or transcribed by XHelpers Pro.
  • If a shortcut does not work, check for conflicts with macOS, another utility such as Rectangle or Rectangle Pro, or another global-shortcut app.

Finder Context Menus

XHelpers Pro uses a bundled Finder extension. macOS controls whether that extension is enabled. You can open the permission and settings flow from the XHelpers Pro menu, or open System Settings and look under Login Items & Extensions.

  • If Finder context menus do not appear, make sure XHelpers Pro is running from Applications.
  • Open XHelpers Pro's menu and choose Configure Finder context menus.
  • If a Finder action cannot open or create an item, macOS may need you to approve folder access.
  • For protected macOS locations, open Full Disk Access settings from XHelpers Pro and enable the app there.

Safes and Archives

Use Finder context menus to encrypt selected local files or folders into a .safe file, add selected items to an existing file, or decrypt selected contents back into a folder. XHelpers Pro can also work with supported .7z, .zip, and .dmg archive flows. Passwords are used only for the action you start and are not stored by XHelpers Pro.

License and Updates

  • XHelpers Pro includes a 14-day trial.
  • License activation uses Lemon Squeezy and stores the license key in your Mac's Keychain.
  • Updates are checked through Sparkle when automatic update checks are enabled or when you choose Check for Updates.

Xin Account and Sign-In

The Xin account is optional. Every local tool, the 14-day trial, and local Pro activation work while you are signed out and while this Mac is offline. If account services are unavailable, XHelpers Pro reports it in the account window and the rest of the app keeps working.

These five terms mean different things and are not interchangeable:

  • Sign-in identity — the email, Google, or Apple identity you authenticate with.
  • Xin account — the Xintech account that holds your product memberships.
  • XHelpers membership — enrollment of that account in XHelpers.
  • Local activation — the license key activated on this Mac; it is what unlocks local Pro features.
  • Server entitlement — paid access recorded on the server for the XHelpers membership.

Creating one never creates the next. Signing in does not create a Xin account, a Xin account does not enroll XHelpers, and neither one activates a license on this Mac.

Each sign-in method recovers differently:

  • Password sign-up — confirm the address from the confirmation email before signing in, and use Resend Code if it did not arrive.
  • Password recovery — request a recovery message, open it on this Mac, then set a new password in the window that opens. Requesting recovery does not sign you in.
  • Sign-in code — request a code and enter it before it expires. Codes are single use; choose Resend Sign-In Code instead of starting a different sign-in.
  • Google — finish the browser step and return to XHelpers Pro. If you cancel it or the callback fails, start the Google step again.
  • Apple — finish the browser step and return to XHelpers Pro. If you cancel it or the callback fails, start the Apple step again. If you chose Hide My Email, account email reaches you through Apple's relay, and turning that relay off in your Apple ID settings stops it.

Two provider identities converge on their own only when the provider confirms the same verified email address. Adding a Google or Apple identity that uses a different address is an explicit linking action in Manage Sign-In Methods.

Keep at least one linked method you can still use. Support cannot reassign, merge, or recover an identity, membership, entitlement, or license from an email address, a display name, a receipt image, or knowledge of a license key.

Signing Out and Deleting

  • Sign Out clears this Mac's session. It does not delete server data, the Xin account, or local activation.
  • Delete XHelpers Data removes the XHelpers membership, the server entitlement, and XHelpers server data. The Xin account, other memberships, the sign-in identity, local files, and local activation stay.
  • Delete Xin Account Everywhere removes every product membership shown in the account, the Xin account, and the sign-in identity, and clears this Mac's session. It does not revoke the authorization on Apple's side; remove XHelpers from Sign in with Apple in your Apple ID settings if you want that. Your local license stays activated.
  • Delete Sign-In Identity applies when you signed in but never created a Xin account.

Each deletion needs a fresh sign-in with a linked method and the exact confirmation text. Once it is accepted it cannot be undone.

If a deletion is interrupted by a network problem, a quit, or a sign-out, reopen the account window and continue it. The pending operation resumes as the same operation; do not start a second deletion.

Support never asks for a password, a sign-in code, a token, a resume credential, or a Keychain export. For an account problem, send the operation identifier shown in the account window and remove anything else from the draft.

Notes

  • XHelpers Pro appears in the macOS menu bar and does not show a Dock icon.
  • Auto Wi-Fi Switch may require Location permission because macOS protects Wi-Fi network names.
  • Keyboard backlight control depends on Mac hardware support.
  • Some display modes, pointer properties, and audio controls depend on macOS version, Mac hardware, and connected devices.
  • Read the XHelpers Pro Privacy Policy for details.
