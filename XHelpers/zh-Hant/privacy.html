隱私權政策

生效日期：2026 年 7 月 6 日。

本文為翻譯版本，以英文版本為準。

XHelpers 是一個本地優先的 macOS 功能表列實用程序，用於顯示 控制項、Finder 上下文選單操作和本機 Safe 加密。

  • 沒有 XHelpers 登入、訂閱帳號或使用者個人資料。
  • 沒有事件追蹤、會話追蹤、廣告像素或使用情況遙測。
  • 顯示、Finder、Safe 和回饋操作在本地運行，除非您選擇發送電子郵件支援。

數據收集

XHelpers 不會收集、儲存、出售、分享或傳輸個人資訊 透過其顯示管理、Finder 操作或 Safe 獲取訊息 加密功能。 Xintech LLC 未收到相關的訊息 您在應用程式中的顯示、檔案、設定、使用情況或設備，除非 您故意透過電子郵件支援發送它。

  • 不需要 XHelpers 帳號。
  • 不包含分析、追蹤 SDK、廣告 SDK 或當機報告 SDK。
  • 沒有後台遙測資料傳送到 Xintech LLC。

本地數據

XHelpers 可以儲存少量本地偏好資料且 Mac 上的有限本地診斷日誌。這是用來製作 應用程式在啟動之間表現一致並準備錯誤報告 當您選擇報告錯誤時草稿。

當地偏好可能包括：

  • 選單設置，例如自動黑屏、鏡像、顯示調整、鍵盤快速鍵和登入時啟動首選項。
  • Finder 上下文選單首選項，包括啟用哪些操作以及您選擇的編輯器、終端或相容應用程式。
  • 資料夾存取書籤、Safe 工作流程首選項和有限的本機診斷訊息。 XHelpers 從不儲存 Safe 密碼。

XHelpers 使用 macOS 顯示 API 進行顯示控制，並使用 macOS 用於 Finder 上下文選單操作的 Finder 擴充 API。 Finder 和 只有當您選擇一個時，Safe 操作才會讀取本機選擇 XHelpers 操作，且 XHelpers 不上傳 Finder 路徑， 檔案內容、Safe 內容或 Safe 密碼到 Xintech LLC。

網路活動

XHelpers 的正常顯示控制項、Finder 上下文功能表和 Safe 加密功能不需要網路連線。更新內容是 透過 Mac App Store 處理。

回饋選單項目會在您的預設電子郵件應用程式中開啟草稿。該應用程式 不會自動發送電子郵件，除非您這樣做，否則不會發送任何內容 選擇發送。

錯誤報告、功能請求和回饋

“報告錯誤...”、“建議功能...”和“發送回饋...” 選單項目在預設電子郵件應用程式中開啟草稿，位址為 Xintech LLC。該應用程式不會自動發送電子郵件。你可以 在發送之前查看、編輯或刪除草稿。

該草案可能包括簡短的診斷摘要，以便支援人員可以 了解上下文：應用程式版本、macOS 版本、處理器 架構、顯示狀態、Finder 擴充狀態、啟用 操作和當前應用程式狀態。您的電子郵件地址可見 Xintech LLC 僅當您發送電子郵件時。

錯誤報告草稿可能包括最近的有限摘錄 XHelpers 診斷日誌。功能請求和一般回饋 草稿不包括日誌。

診斷和日誌

XHelpers 將診斷訊息寫入蘋果本地統一 日誌系統並保留一個小的有界應用程式本地診斷日誌。 這些日誌本機儲存在您的 Mac 上。選擇“報告錯誤...” 可以從應用程式本地收集僅限 XHelpers 的有限摘錄 記錄並將其插入電子郵件草稿中。

除非您選擇發送，否則不會發送任何內容，並且您可以刪除 發送錯誤報告之前的診斷摘要或日誌摘錄。

您的選擇

  • 您可以保留未發送的回饋草稿、對其進行編輯或刪除診斷詳細資訊。
  • 您可以在 macOS 設定中啟用或停用 Finder 擴充功能。
  • 您可以使用普通的 macOS 首選項管理工具刪除本機應用程式首選項和資料夾核准。
