Dasar Privasi

Tarikh berkuat kuasa: 6 Julai 2026.

Ini ialah terjemahan. Versi bahasa Inggeris ialah versi yang berkuat kuasa.

XHelpers ialah utiliti bar menu macOS yang pertama tempatan untuk paparan kawalan, tindakan menu konteks Finder dan penyulitan Safe setempat.

  • Tiada XHelpers log masuk, akaun langganan atau profil pengguna.
  • Tiada penjejakan acara, penjejakan sesi, piksel pengiklanan atau telemetri penggunaan.
  • Tindakan paparan, Finder, Safe dan maklum balas dijalankan secara setempat melainkan anda memilih untuk menghantar sokongan e-mel.

Pengumpulan Data

XHelpers tidak mengumpul, menyimpan, menjual, berkongsi, atau menghantar peribadi maklumat melalui pengurusan paparannya, tindakan Finder atau Safe ciri penyulitan. Xintech LLC tidak menerima maklumat tentang paparan, fail, tetapan, penggunaan atau peranti anda daripada apl melainkan anda sengaja menghantarnya melalui sokongan e-mel.

  • Tiada akaun XHelpers diperlukan.
  • Tiada analitis, SDK penjejakan, SDK pengiklanan atau SDK pelaporan ranap sistem disertakan.
  • Tiada telemetri latar belakang dihantar ke Xintech LLC.

Data Tempatan

XHelpers boleh menyimpan sejumlah kecil data keutamaan tempatan dan log diagnostik tempatan bersempadan pada Mac anda. Ini digunakan untuk membuat apl berkelakuan secara konsisten antara pelancaran dan untuk menyediakan laporan pepijat draf apabila anda memilih untuk melaporkan pepijat.

Pilihan tempatan mungkin termasuk:

  • Tetapan menu seperti pemadaman automatik, pencerminan, pelarasan paparan, pintasan papan kekunci dan pilihan mula semasa log masuk.
  • Finder pilihan menu konteks, termasuk tindakan yang didayakan dan editor, terminal atau apl yang serasi yang anda pilih.
  • Penanda halaman akses folder, pilihan aliran kerja Safe dan mesej diagnostik setempat terhad. XHelpers tidak pernah menyimpan kata laluan Safe.

XHelpers menggunakan macOS API paparan untuk kawalan paparan dan macOS Finder API sambungan untuk Finder tindakan menu konteks. Finder dan Operasi Safe membaca pilihan tempatan hanya apabila anda memilih a XHelpers tindakan dan XHelpers tidak memuat naik Finder laluan, kandungan fail, kandungan Safe atau Safe kata laluan ke Xintech LLC.

Aktiviti Rangkaian

Kawalan paparan biasa XHelpers, menu konteks Finder dan Safe ciri penyulitan tidak memerlukan sambungan rangkaian. Kemas kini adalah dikendalikan melalui Mac App Store.

Item menu maklum balas membuka draf dalam apl e-mel lalai anda. Aplikasi itu tidak menghantar e-mel secara automatik, dan tiada apa yang dihantar melainkan anda pilih Hantar.

Laporan Pepijat, Permintaan Ciri dan Maklum Balas

"Laporkan Pepijat...", "Cadangkan Ciri..." dan "Hantar Maklum Balas..." item menu buka draf dalam apl e-mel lalai anda yang ditujukan kepada Xintech LLC. Aplikasi ini tidak menghantar e-mel secara automatik. awak boleh semak, edit atau padam draf sebelum menghantarnya.

Draf mungkin termasuk ringkasan diagnostik pendek supaya sokongan boleh fahami konteks: versi apl, versi macOS, pemproses seni bina, keadaan paparan, Finder keadaan sambungan, didayakan tindakan, dan status apl semasa. Alamat e-mel anda kelihatan kepada Xintech LLC hanya jika anda menghantar e-mel.

Draf laporan pepijat mungkin termasuk petikan terhad baru-baru ini XHelpers log diagnostik. Permintaan ciri dan maklum balas umum draf tidak termasuk log.

Diagnostik dan Log

XHelpers menulis mesej diagnostik ke united tempatan Apple sistem pengelogan dan menyimpan log diagnostik apl-tempatan bersempadan kecil. Log ini disimpan secara setempat pada Mac anda. Memilih "Laporkan Pepijat..." boleh mengumpul petikan XHelpers-sahaja yang terhad daripada app-local log dan masukkan ke dalam draf e-mel.

Tiada apa-apa dihantar melainkan anda memilih Hantar dan anda boleh memadamkan ringkasan diagnostik atau petikan log sebelum menghantar laporan pepijat.

Pilihan Anda

  • Anda boleh membiarkan draf maklum balas tidak dihantar, mengeditnya atau memadamkan butiran diagnostik.
  • Anda boleh mendayakan atau melumpuhkan sambungan Finder dalam tetapan macOS.
  • Anda boleh mengalih keluar keutamaan apl tempatan dan kelulusan folder menggunakan alat pengurusan keutamaan macOS biasa.

Analitik laman web

Laman web ini menggunakan Umami Cloud, perkhidmatan analitik tanpa kuki, untuk mengira lawatan halaman dan tindakan asas laman web seperti klik App Store, muat turun, sokongan, privasi, terma dan pautan e-mel. Metrik laman web ini membantu Xintech LLC memahami halaman yang berguna. Ia berasingan daripada aplikasi itu sendiri; aplikasi tidak menyertakan SDK analitik dan tidak menghantar telemetri penggunaan aplikasi kepada Xintech LLC.
