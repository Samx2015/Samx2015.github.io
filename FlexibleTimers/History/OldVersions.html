Version 3.5.2 is a temporary direct build for testing, separate from the Mac App Store release. It is not notarized, so macOS may show a security warning on first launch. To install either ZIP build, unzip it and move XTimers to Applications. Version 3.5.1 preserves the original Mac App Store-signed app. Versions 3.4.0 and 2.1.12 are historical source builds signed by Xintech LLC with Developer ID and notarized by Apple. For the current version, visit the XTimers home page.
