Politique de confidentialité

Date d'entrée en vigueur : 6 juillet 2026.

Ceci est une traduction. La version anglaise fait foi.

XHelpers est un premier utilitaire de barre de menu macOS local pour l'affichage contrôles, actions du menu contextuel Finder et cryptage local Safe.

  • Pas de connexion XHelpers, de compte d'abonnement ou de profil utilisateur.
  • Pas de suivi des événements, de suivi de session, de pixels publicitaires ou de télémétrie d'utilisation.
  • Les actions d'affichage, Finder, Safe et de commentaires s'exécutent localement, sauf si vous choisissez d'envoyer une assistance par e-mail.

Collecte de données

XHelpers ne collecte, ne stocke, ne vend, ne partage ni ne transmet des informations personnelles. informations via sa gestion de l'affichage, l'action Finder ou Safe fonctionnalités de cryptage. Xintech LLC ne reçoit pas d'informations sur vos écrans, fichiers, paramètres, utilisation ou appareil depuis l'application, sauf si vous l'envoyez intentionnellement via l'assistance par e-mail.

  • Aucun compte XHelpers n’est requis.
  • Aucun SDK d'analyse, de suivi, de publicité ou de rapport d'erreur n'est inclus.
  • Aucune télémétrie en arrière-plan n'est envoyée à Xintech LLC.

Données locales

XHelpers peut stocker une petite quantité de données de préférences locales et journaux de diagnostic locaux limités sur votre Mac. Ceci est utilisé pour faire le l'application se comporte de manière cohérente entre les lancements et pour préparer un rapport de bug brouillons lorsque vous choisissez de signaler un bug.

Les préférences locales peuvent inclure :

  • Paramètres de menu tels que la panne automatique, la mise en miroir, le réglage de l'affichage, les raccourcis clavier et les préférences de démarrage à la connexion.
  • Préférences du menu contextuel Finder, y compris les actions activées et l'éditeur, le terminal ou l'application compatible que vous avez sélectionné.
  • Signets d'accès aux dossiers, préférences de flux de travail Safe et messages de diagnostic locaux limités. XHelpers ne stocke jamais les mots de passe Safe.

XHelpers utilise les API d'affichage macOS pour les contrôles d'affichage et macOS API d'extension Finder pour les actions du menu contextuel Finder. Finder et Les opérations Safe lisent les sélections locales uniquement lorsque vous choisissez un Action XHelpers, et XHelpers ne télécharge pas les chemins Finder, contenu du fichier, contenu Safe ou mots de passe Safe vers Xintech LLC.

Activité réseau

Commandes d'affichage normales de XHelpers, menus contextuels de Finder et Safe les fonctionnalités de cryptage ne nécessitent pas de connexion réseau. Les mises à jour sont géré via le Mac App Store.

Les éléments du menu Commentaires ouvrent un brouillon dans votre application de messagerie par défaut. L'application n'envoie pas d'e-mail automatiquement et rien n'est envoyé sauf si vous choisissez Envoyer.

Rapports de bogues, demandes de fonctionnalités et commentaires

Les options "Signaler un bug...", "Suggérer une fonctionnalité..." et "Envoyer des commentaires..." les éléments de menu ouvrent un brouillon dans votre application de messagerie par défaut adressé à Xintech LLC. L'application n'envoie pas d'e-mail automatiquement. Vous pouvez révisez, modifiez ou supprimez le brouillon avant de l’envoyer.

Le projet peut inclure un bref résumé de diagnostic afin que le support puisse comprendre le contexte : version de l'application, version macOS, processeur architecture, état d'affichage, état de l'extension Finder, activé actions et l'état actuel de l'application. Votre adresse e-mail est visible par Xintech LLC seulement si vous envoyez l'e-mail.

Les brouillons de rapport de bug peuvent inclure un extrait limité des récents Journaux de diagnostic XHelpers. Demande de fonctionnalité et commentaires généraux les brouillons n’incluent pas les journaux.

Diagnostics et journaux

XHelpers écrit des messages de diagnostic sur le réseau local unifié d'Apple système de journalisation et conserve un petit journal de diagnostic local d'application limité. Ces journaux sont stockés localement sur votre Mac. En choisissant "Signaler un bug..." peut collecter un extrait limité XHelpers uniquement de l'application locale log et insérez-le dans le brouillon de l’e-mail.

Rien n'est envoyé sauf si vous choisissez Envoyer et vous pouvez supprimer le résumé du diagnostic ou extrait du journal avant d’envoyer des rapports de bogues.

Vos choix

  • Vous pouvez laisser les brouillons de commentaires non envoyés, les modifier ou supprimer les détails du diagnostic.
  • Vous pouvez activer ou désactiver l'extension Finder dans les paramètres macOS.
  • Vous pouvez supprimer les préférences des applications locales et les approbations de dossiers à l'aide des outils de gestion des préférences macOS normaux.

Analyse du site web

Ce site web utilise Umami Cloud, un service d’analyse sans cookies, pour compter les visites de pages et les actions de base du site, comme les clics vers l’App Store, les téléchargements, l’assistance, la confidentialité, les conditions et les liens e-mail. Ces mesures aident Xintech LLC à comprendre quelles pages sont utiles. Elles sont distinctes des apps elles-mêmes, qui n’incluent pas de SDK d’analyse et n’envoient pas de télémétrie d’utilisation de l’app à Xintech LLC.

Pour des questions de confidentialité ou d'assistance, contactez Xintech LLC à admin@xintechllc.com.
