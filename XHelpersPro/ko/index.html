Mac 메뉴 막대 디스플레이 도우미

XHelpers Pro

유용한 데스크 기능을 하나의 Mac 유틸리티로.

XHelpers Pro는 디스플레이 제어, 윈도우 단축 동작, Finder 동작, 로컬 파일 보호, 입력 장치 튜닝, 앱 오디오 제어, 그리고 프라이버시 중심 설계를 하나의 메뉴 막대 앱에 담았습니다.

디스플레이 제어 윈도우 단축 동작 Finder 동작 암호화·압축(.safe/.7z/.zip/.dmg) 마우스 감도와 스크롤 속도 키/버튼 리매핑 앱 오디오 믹서 프라이버시 우선

디스플레이·윈도우 제어

시스템 설정, 서드파티 윈도우 도구, 디스플레이 메뉴를 오가지 않고 작업 화면을 관리하세요.

  • 외장 모니터로 미러링하는 동안 MacBook 내장 화면을 블랙아웃.
  • 미러링 전환, 키 입력 전까지 화면 어둡게, 잠자기, 재시동, 시스템 종료, 밝기·대비 조절.
  • 지원되는 HiDPI/사용자 지정 디스플레이 모드 설치와 전환.
  • 윈도우를 절반, 모서리, 가운데, 전체 화면 배치, 다른 디스플레이나 데스크탑으로 이동.
  • 활성 윈도우를 클릭이 통과되는 사용자 지정 테두리로 하이라이트.
정렬된 윈도우 포커스 기능과 Rectangle/Rectangle Pro 충돌 안내를 포함합니다.

Finder 동작과 로컬 금고

선택한 파일, 암호, 암호화된 금고를 Mac 안에 두면서 Finder를 더 유용하게.

  • Finder에서 바로 새 파일과 폴더 만들기.
  • 붙여넣기, 이동, 경로 복사, 그리고 Terminal, TextEdit, VS Code, Codex, Claude 등 지원 앱에서 폴더 열기.
  • 선택한 파일이나 폴더를 로컬 .safe 파일로 암호화.
  • 기존 금고에 파일 추가 또는 선택한 항목만 복호화.
  • .7z, .zip, .dmg 아카이브 흐름 지원.
Finder·금고 동작은 우클릭 메뉴에서 XHelpers Pro 동작을 선택할 때만 실행됩니다.

포인터·스크롤·입력 프로파일

마우스, 포인팅 장치, 키보드 동작, 버튼 매핑을 장치별로 튜닝하세요.

  • 마우스별 포인터 감도·가속도 조절.
  • 포인팅 장치별 스크롤 속도·가속도 설정.
  • LinearMouse 호환 스케일링의 선형 스크롤.
  • 키나 지원 마우스 버튼을 키, 단축키, 듀얼 역할 키, Hyper 스타일 수정 키로 리매핑.
  • 프로파일과 규칙은 모두 이 Mac에만 저장.
한 책상에 여러 마우스·키보드나 작업별 단축키가 있을 때 유용합니다.

앱 오디오·데스크 유틸리티

여러 앱에 흩어져 작업을 방해하는 자잘한 데스크 요소를 한곳에서 제어하세요.

  • 메뉴 막대에서 앱별 음량 설정.
  • 소리가 작은 앱을 최대 200%까지 증폭.
  • 앱 개별 음소거.
  • 신호가 약해지면 자동 Wi-Fi 전환이 더 나은 알려진 AP로 연결.
  • Dock 윈도우 없이 메뉴 막대에서 실행.
오디오 믹서는 macOS 14.4 이상에서 시스템 오디오 녹음 권한이 필요하며, 오디오는 로컬에서만 처리됩니다.

프라이버시 우선

XHelpers Pro는 로컬 Mac 워크플로를 위해 만들어졌습니다. 데스크 유틸리티를 또 하나의 계정, 분석 스트림, 클라우드 파일 서비스로 만들지 않습니다.

  • 계정이 필요 없습니다.
  • 분석, 광고 SDK, 사용 원격 측정, 세션 추적이 없습니다.
  • Wi-Fi 암호를 수집하지 않고 금고 암호를 기록하지 않습니다.
  • 평문 내용, 금고 암호, 암호화 키, 포인터 프로파일, 리매핑 규칙, 오디오 처리는 모두 로컬에 남습니다.
  • 선택 권한은 모두 명확히 설명됩니다: 손쉬운 사용, 입력 모니터링, 시스템 오디오 녹음, 위치, Finder 확장, 전체 디스크 접근.
무엇이 좋나요?

책상에서 덜 번거롭게.

  • 필요할 때만 어둡게 미러링 중에는 어둡게, MacBook 화면을 작업 공간으로 쓸 때는 정상 표시
  • 빠른 일상 동작 미러링 전환, 키 입력까지 어둡게, 잠자기, 디스플레이 수준 조절, 필요 시 Wi-Fi 전환을 빠르게 수행합니다
  • 유용하지만 조용함 Dock 창, 계정, 분석 없이 메뉴 막대에서 실행됩니다
책상 설정용 외부 디스플레이에 자주 연결되는 MacBook을 위해 만들었습니다
빠른 제어용 메뉴가 앱입니다. 관리할 추가 창이 없습니다
