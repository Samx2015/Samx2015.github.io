Flexible Timers by Xintech LLC SMS 条款

Flexible Timers由Xintech LLC运营。 Flexible Timers可发送SMS 仅向登录用户添加、验证和验证的电话号码发送消息 选择作为自己的帐户电话号码。目前的SMS程序是 仅限账户电话验证码和用户创建的计时器/提醒 用户为自己安排的SMS。 Flexible Timers 不发送 营销短信并且不允许用户发送SMS到任意 第三方收件人。 Flexible Timers SMS 不是双向聊天或 会话服务；入站关键字仅用于 STOP、HELP、START、 和YES合规处理。

选择加入

用户通过输入电话号码在 Flexible Timers 应用程序内选择加入 并肯定地选中未预先选择的框。复选框 说：“我同意接收SMS验证码和提醒消息 来自 Flexible Timers by Xintech LLC 我为自己安排的 电话号码。”选择加入屏幕还显示这些 SMS 条款、 隐私政策、标准消息和数据速率披露、STOP 和 HELP 说明、消息频率信息和非营销语言。 同意不是购买的条件。 请参阅选择加入证据页面： xintechllc.com/FlexibleTimers/zh-Hans/sms-opt-in.html。

消息频率

消息频率各不相同。 Flexible Timers 发送验证消息时 用户请求验证自己的帐户电话号码。Flexible Timers 仅当经过验证的帐户所有者创建并 为自己安排 SMS 提醒。用户无法发送聊天回复 或由 SMS 向 Flexible Timers 发送用户编写的消息。

费用

可能适用标准消息和数据速率。消息和数据速率为 由您的移动运营商收取费用，并且由您负责。

选择退出

回复 STOP 以选择退出来自 Flexible Timers 的 SMS 消息。发送后 STOP、Flexible Timers 将停止向该电话号码发送 SMS 消息 除非您再次选择加入。

帮助

回复 HELP 寻求帮助。您还可以联系 Flexible Timers 支持： xintechllc.com/FlexibleTimers/zh-Hans/support.html。

SMS 关键字和响应

STOP 从 Flexible Timers SMS 中选择电话号码。预期的 STOP 回复是：“您已选择退出 Flexible Timers SMS。没有更多消息 将被发送。回复 START 以再次选择加入。”

HELP 请求支持信息。预期的 HELP 响应是： 》Flexible Timers发送账户验证码并提醒SMS您 为自己制定时间表。帮助：https://xintechllc.com/FlexibleTimers/support.html。回复 STOP 选择退出。”

START 或 YES 在 用户已经为该帐户电话提供了应用程序同意。预期的START 回应是： “您已选择重新加入 Flexible Timers SMS 消息。消息频率 各不相同。回复 STOP 选择退出，回复 HELP 寻求帮助。”

承运人责任

无线运营商对延迟或未送达的消息不承担任何责任。

隐私

请参阅 Flexible Timers 隐私政策： xintechllc.com/FlexibleTimers/zh-Hans/privacy.html。
