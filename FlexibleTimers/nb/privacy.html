Flexible Timers by Xintech LLC Retningslinjer for personvern

Denne oversettelsen er gitt for enkelhets skyld. Den engelske versjonen er den autoritative versjonen. English.

Flexible Timers drives av Xintech LLC. Flexible Timers bruker konto informasjon for å gi timer, påminnelse, konto, synkronisering, rapport, og meldingsfunksjoner. Flexible Timers sender for tiden e-postrapporter og e-postmeldinger kun til den påloggede brukerens egen konto-e-postadresse. Denne policyen beskriver også SMS personvernvilkår for kontotelefon verifisering og brukeropprettede SMS-påminnelser sendt kun til brukerens egne bekreftet, påmeldt kontotelefonnummer.

Informasjon samlet for e-post

Når en pålogget bruker ber om bekreftelse, en rapport, tilbakemelding eller en e-postpåminnelse, kan Flexible Timers behandle brukerens konto-e-post adresse, meldingsinnhold, tidtaker/rapportdata som trengs for forespørselen, og leveringsmetadata som trengs for å betjene, feilsøke og sikre tjenesten.

Informasjon samlet inn for SMS

Når en pålogget bruker legger til sitt eget kontotelefonnummer for SMS, Flexible Timers kan lagre telefonnummeret, samtykkestatus, samtykke kilde, samtykketekstversjon, samtykketekst, SMS-vilkår URL, Personvern Policy-URL, tidsstempel, bekreftelsesstatus, brukeropprettet påminnelsesmelding innhold, planlagt påminnelsestid og metadata for meldingslevering nødvendig drifte og revidere SMS-programmet.

Hvordan SMS-informasjon brukes

SMS informasjon brukes til å bekrefte brukerens eget telefonnummer, send påminnelse SMS at brukeren planlegger for seg selv, opprettholde opt-in og velge bort poster, forhindre misbruk, feilsøke levering og overholde transportør og juridiske krav.

Ingen markedsføringssalg eller deling

Flexible Timers selger ikke SMS-samtykkedata. Flexible Timers gjør det ikke dele SMS-samtykkedata, telefonnumre eller tekstmeldingssamtykke med tredjepart parter eller tilknyttede selskaper for markedsføring eller reklameformål.

Tjenesteleverandører

Flexible Timers kan bruke tjenesteleverandører, inkludert SMS-leverandører, for å levere bekreftelsesmeldinger, levere brukerplanlagt påminnelse SMS, og drifte tjenesten. Disse leverandørene kan kun behandle SMS informasjon som nødvendig for å tilby meldingstjenesten.

Velg bort

Brukere kan svare STOP for å velge bort SMS-meldinger. Brukere kan svare HELP for hjelp.
