Flexible Timers by Xintech LLC SMS 條款

提供此翻譯是為了方便。英文版為權威版本。 English.

Flexible Timers由Xintech LLC營運。 Flexible Timers可傳送SMS 僅向登入使用者新增、驗證和驗證的電話號碼傳送訊息 選擇作為自己的帳戶電話號碼。目前的SMS程式是 僅限帳戶電話驗證碼和使用者建立的計時器/提醒 使用者為自己安排的SMS。 Flexible Timers 不傳送 行銷簡訊且不允許使用者傳送SMS到任意 第三方收件人。 Flexible Timers SMS 不是雙向聊天或 會話服務；入站關鍵字僅用於 STOP、HELP、START、 和YES合規處理。

選擇加入

使用者透過輸入電話號碼在 Flexible Timers 應用程式內選擇加入 並肯定地選取未預先選取的方塊。核取方塊 說：「我同意接收SMS驗證碼和提醒訊息 來自 Flexible Timers by Xintech LLC 我為自己安排的 電話號碼。 」選擇加入畫面也顯示這些 SMS 條款、 隱私權政策、標準訊息和資料速率揭露、STOP 和 HELP 說明、訊息頻率資訊和非行銷語言。 同意不是購買的條件。 請參閱選擇加入證據頁面： xintechllc.com/sms-opt-in.html。

訊息頻率

訊息頻率各不相同。 Flexible Timers 傳送驗證訊息時 使用者要求驗證自己的帳戶電話號碼。Flexible Timers 僅當經過驗證的帳戶所有者建立並 為自己安排 SMS 提醒。使用者無法傳送聊天回覆 或由 SMS 向 Flexible Timers 傳送使用者編寫的訊息。

費用

可能適用標準訊息和資料速率。訊息和資料速率為 由您的移動運營商收取費用，並且由您負責。

選擇退出

回覆 STOP 以選擇退出來自 Flexible Timers 的 SMS 訊息。傳送後 STOP、Flexible Timers 將停止向該電話號碼傳送 SMS 訊息 除非您再次選擇加入。

幫助

回覆 HELP 尋求協助。您也可以聯絡 Flexible Timers 支援： xintechllc.com/support.html。

SMS 關鍵字和回應

STOP 從 Flexible Timers SMS 中選擇電話號碼。預期的 STOP 回覆是：「您已選擇退出 Flexible Timers SMS。沒有更多訊息 將被傳送。回覆 START 以再次選擇加入。 」

HELP 請求支援資訊。預期的 HELP 回應是： 》Flexible Timers傳送帳戶驗證碼並提醒SMS您 為自己制定時間表。幫助：https://xintechllc.com/support.html。回覆 STOP 選擇退出。 」

START 或 YES 在 使用者已經為該帳戶電話提供了應用程式同意。預期的START 回應是： “您已選擇重新加入 Flexible Timers SMS 訊息。訊息頻率 各不相同。回覆 STOP 選擇退出，回覆 HELP 尋求協助。 」

承運人責任

無線運營商對延遲或未送達的訊息不承擔任何責任。

隱私

請參閱 Flexible Timers 隱私權政策： xintechllc.com/privacy.html。
