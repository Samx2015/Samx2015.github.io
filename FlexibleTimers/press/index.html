A workspace for different kinds of time.

XTimers combines named timers, countdowns, reusable task sets and world clocks. The menu-bar reading keeps a task visible while you use other Mac apps, and local reports help you review recorded time.

XTimers 3.5.0 includes World Calendar, with regional holidays and countdowns created from dates, alongside flexible timer views, report charts and sound controls. Calendar data needs an initial download. Personal Apple Calendar events are an optional, read-only view.

The free-download fact describes the current App Store price. Connected services have their own eligibility and terms.

Short description

XTimers is a Mac app for keeping several kinds of time in view. Run count-up timers and countdowns, organize reusable task sets, keep world clocks nearby and review where your time went. Core timers and local reports work offline without an account.

  1. 0:00–0:10 — Keep your time moving. Studio’s Grid View shows five elapsed timers, a countdown and three world clocks. Planning changes from paused to running, and its elapsed seconds advance.
  2. 0:10–0:17 — Keep time in sight. The native Mac menu-bar item shows Planning’s live reading advancing.
  3. 0:17–0:28.5 — Know where time went. Reports shows five selected sample tasks for September 21–25, 2026, with 30 total hours, daily totals and each task’s share of time.
  4. 0:28.5–0:40 — See when work happened. The Sessions tab shows the same period and tasks as a timeline of recorded work sessions.
