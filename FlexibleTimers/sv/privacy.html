Sekretesspolicy för Flexible Timers by Xintech LLC

Denna översättning tillhandahålls för bekvämlighets skull. Den engelska versionen är den auktoritativa versionen. English.

Flexible Timers drivs av Xintech LLC. Flexible Timers använder kontoinformation för att tillhandahålla timer-, påminnelse-, konto-, synkroniserings-, rapport- och meddelandefunktioner. Flexible Timers skickar för närvarande e-postrapporter och e-postmeddelanden endast till e-postadressen för den inloggade användarens eget konto. Denna policy beskriver även sekretessvillkoren för SMS vid verifiering av kontotelefonnummer och användarskapade SMS-påminnelser som endast skickas till användarens eget verifierade och anmälda kontotelefonnummer.

Information som samlas in för e-post

När en inloggad användare begär verifiering, en rapport, feedback eller en e-postpåminnelse kan Flexible Timers behandla e-postadressen för användarens konto, meddelandeinnehåll, timer-/rapportdata som behövs för begäran och leveransmetadata som behövs för att driva, felsöka och säkra tjänsten.

Information insamlad för SMS

När en inloggad användare lägger till sitt eget kontotelefonnummer för SMS kan Flexible Timers lagra telefonnumret, samtyckesstatus, samtyckeskälla, samtyckestextversion, samtyckesformulering, URL till SMS-villkor, URL till sekretesspolicy, tidsstämpel, verifieringsstatus, innehåll i användarskapade påminnelser, schemalagd påminnelsetid och metadata för meddelandeleverans som behövs för att driva och granska SMS-programmet.

Hur SMS-information används

SMS-information används för att verifiera användarens eget kontotelefonnummer, skicka SMS-påminnelser som användaren schemalägger för sig själv, behålla uppgifter om anmälan och avanmälan, förhindra missbruk, felsöka leverans och följa operatörskrav och juridiska krav.

Ingen marknadsföringsförsäljning eller delning

Flexible Timers säljer inte SMS-samtyckesdata. Flexible Timers delar inte SMS-samtyckesdata, telefonnummer eller samtycke till textmeddelanden med tredje parter eller närstående bolag i marknadsförings- eller reklamsyfte.

Tjänsteleverantörer

Flexible Timers kan använda tjänsteleverantörer, inklusive SMS-leverantörer, för att leverera verifieringsmeddelanden, leverera SMS-påminnelser som användaren schemalagt och driva tjänsten. Dessa leverantörer får endast behandla SMS-information i den utsträckning som behövs för att tillhandahålla meddelandetjänsten.

Avanmälan

Användare kan svara STOP för att avanmäla sig från SMS-meddelanden. Användare kan svara HELP för hjälp.

Kontakt
