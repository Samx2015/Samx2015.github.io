What XHelpers Pro does

XHelpers Pro combines everyday desk utilities in one Mac menu-bar app: display control and MacBook blackout while mirroring, window arrangement shortcuts, Finder context-menu actions with local file encryption, per-device pointer and scroll tuning, key and mouse button remapping, and a per-app audio mixer — private by design, with no account required for the local tools.

It runs on Macs with macOS 13.0 or later (Apple Silicon and Intel). XHelpers Pro is a Mac app — it does not run on iPhone or iPad.
