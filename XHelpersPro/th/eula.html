ข้อตกลงสิทธิ์การใช้งานสำหรับผู้ใช้ปลายทาง XHelpers Pro

วันที่มีผลบังคับใช้: 2026-09-04

ข้อตกลงสิทธิ์การใช้งานสำหรับผู้ใช้ปลายทางฉบับนี้ ("ข้อตกลง") ควบคุมการใช้ XHelpers Pro ("ซอฟต์แวร์") ของคุณ ซึ่งเป็นยูทิลิตี้ macOS ที่ให้บริการโดย Xintech LLC ("Xintech", "เรา" หรือ "ของเรา")

เมื่อคุณติดตั้ง คัดลอก หรือใช้ซอฟต์แวร์ ถือว่าคุณยอมรับข้อตกลงนี้ หากไม่ยอมรับ โปรดอย่าติดตั้งหรือใช้ซอฟต์แวร์

คำแปลนี้จัดทำขึ้นเพื่อความสะดวกของคุณ เฉพาะฉบับภาษาอังกฤษเท่านั้นที่มีผลเหนือกว่าเท่าที่กฎหมายที่ใช้บังคับอนุญาต โดยไม่กระทบสิทธิ์ผู้บริโภคภาคบังคับในท้องถิ่น

1. การให้สิทธิ์ใช้งาน

Xintech ให้สิทธิ์แบบจำกัด ไม่ผูกขาด โอนไม่ได้ และเพิกถอนได้แก่คุณ เพื่อติดตั้งและใช้ซอฟต์แวร์บนคอมพิวเตอร์ Mac ที่คุณเป็นเจ้าของหรือควบคุม สำหรับการใช้งานส่วนบุคคลหรือภายในธุรกิจของคุณเท่านั้น

2. ข้อจำกัด

คุณต้องไม่:

  • ขาย ให้เช่า ให้เช่าซื้อ ให้สิทธิ์ช่วง หรือโฮสต์ซอฟต์แวร์ในเชิงพาณิชย์
  • แจกจ่ายซอฟต์แวร์อีกครั้ง เว้นแต่ผ่านช่องทางเผยแพร่อย่างเป็นทางการที่ Xintech อนุมัติ
  • แก้ไข ดัดแปลง แปล หรือสร้างผลงานต่อเนื่องจากซอฟต์แวร์
  • ทำวิศวกรรมย้อนกลับ ดีคอมไพล์ หรือแยกส่วนซอฟต์แวร์ เว้นแต่กฎหมายที่ใช้บังคับอนุญาตไว้อย่างชัดแจ้ง
  • ลบหรือเปลี่ยนประกาศลิขสิทธิ์ สิทธิ์ใช้งาน หรือกรรมสิทธิ์ หรือ
  • ใช้ซอฟต์แวร์ในลักษณะที่ละเมิดกฎหมายที่ใช้บังคับ

3. กรรมสิทธิ์

ซอฟต์แวร์ได้รับอนุญาตให้ใช้ ไม่ได้จำหน่าย Xintech และผู้ให้สิทธิ์ของบริษัทสงวนสิทธิ์ กรรมสิทธิ์ และผลประโยชน์ทั้งหมดในซอฟต์แวร์ รวมถึงสิทธิ์ในทรัพย์สินทางปัญญาทั้งหมด ไม่มีการให้สิทธิ์ใดนอกจากที่ระบุไว้อย่างชัดแจ้งในข้อตกลงนี้

4. คุณสมบัติ สิทธิ์ และข้อมูลผู้ใช้

ซอฟต์แวร์มีชุดยูทิลิตี้ macOS ภายในเครื่องซึ่งเปลี่ยนแปลงได้ ขึ้นอยู่กับรุ่นที่ติดตั้ง โดยอาจรวมเครื่องมือจอภาพ ความละเอียดแบบกำหนดเอง หน้าต่าง โฟกัส อินพุต เสียง คำบรรยาย Wi-Fi ไฟพื้นหลังแป้นพิมพ์ การจับภาพหน้าจอ OCR การแปล รูปภาพ PDF ข้อความ Markdown การดูไบนารี Finder คลิปบอร์ด ไฟล์เก็บถาวร Safe การติดตั้งแอป แบบอักษร พื้นที่จัดเก็บ รายการซ้ำซ้อน การเริ่มทำงาน สุขภาพระบบ การบำรุงรักษา การเรียกคืนพื้นที่ และการถอนการติดตั้ง ซอฟต์แวร์อาจมีการกำหนดค่า “นำ AI ของคุณมาใช้” ที่เลือกได้และการทดสอบผู้ให้บริการขั้นต่ำสำหรับการผสานรวม OpenAI, Anthropic และ xAI ที่รองรับ คุณสมบัติที่ใช้ได้ขึ้นอยู่กับรุ่นที่ติดตั้ง ฮาร์ดแวร์ Mac, macOS, สิทธิ์ และซอฟต์แวร์ของบริษัทอื่น

คุณสมบัติบางอย่างต้องใช้สิทธิ์การช่วยการเข้าถึง การตรวจสอบอินพุต การบันทึกหน้าจอ การบันทึกเสียงระบบ การรู้จำเสียงพูด ตำแหน่ง การทำงานอัตโนมัติ การเข้าถึงดิสก์แบบเต็ม การแจ้งเตือน การอนุญาตจากผู้ดูแลระบบ หรือตัวช่วยที่มีสิทธิ์ คุณมีหน้าที่ตัดสินใจว่าจะให้สิทธิ์หรือไม่ และเพิกถอนได้ในการตั้งค่าระบบ macOS แม้ว่าคุณสมบัติที่เกี่ยวข้องอาจหยุดทำงาน

การดำเนินการกับไฟล์ Finder คลิปบอร์ด ไฟล์เก็บถาวร Safe รูปภาพ PDF การติดตั้ง การถอนการติดตั้ง การเรียกคืนพื้นที่ จอภาพ ความละเอียด เสียง ตัวชี้ การแมปใหม่ และระบบ สามารถสร้าง คัดลอก ย้าย แปลง แทนที่ ลบ ติดตั้ง หรือเปิดเผยเนื้อหา หรือเปลี่ยนพฤติกรรมของแอปหรือระบบได้ โปรดเก็บข้อมูลสำรองแยกต่างหาก ตรวจสอบปลายทางและผลลัพธ์ และอย่าใช้สำเนาข้อมูลสำคัญเพียงชุดเดียวในการทดสอบ Image Tools และ PDF Quick Actions ปัจจุบันออกแบบมาเพื่อเผยแพร่ผลลัพธ์ใหม่โดยไม่เขียนทับอินพุต แต่คุณยังคงมีหน้าที่ตรวจทานผลลัพธ์ทุกชิ้น ความถูกต้องของ PDF ขึ้นอยู่กับ PDFKit ของ Apple และการดำเนินการอาจปฏิเสธ รักษา เปลี่ยน หรือทำให้คำอธิบายประกอบ แบบฟอร์ม สิทธิ์ การเข้ารหัส หรือลายเซ็นดิจิทัลใช้ไม่ได้ ซอฟต์แวร์ไม่ใช่เครื่องมือตรวจสอบลายเซ็นทางกฎหมาย บริการปกปิดข้อมูลที่ผ่านการรับรอง บริการรักษาความถูกต้องของไฟล์เก็บถาวร หรือสิ่งทดแทนการตรวจทานผลลัพธ์ Xintech ไม่สามารถกู้คืนรหัสผ่าน Safe ไฟล์เก็บถาวร หรือ PDF ที่ลืม และไม่มีคีย์เข้ารหัสภายในเครื่องของคุณ Font Manager ดาวน์โหลดเฉพาะตระกูลแบบอักษรที่คุณเลือกและประกาศใบอนุญาตของแบบอักษรเหล่านั้นจากคลัง Google Fonts แบบตรึงที่โฮสต์โดย GitHub โดยเก็บสำเนาที่จัดการและบันทึกความเป็นเจ้าของไว้ใน Application Support ลงทะเบียนแบบอักษรเหล่านั้นอย่างถาวรสำหรับผู้ใช้ปัจจุบัน และเมื่อคุณเลือกนำออก จะลบเฉพาะสำเนาที่จัดการซึ่งผ่านการตรวจสอบแล้ว App Installer อาจติดตั้ง Apple Command Line Tools ดาวน์โหลดและติดตั้ง Homebrew รุ่นที่ตรึงไว้ ใช้ Homebrew ดาวน์โหลดและติดตั้ง formula หรือ cask ของบุคคลที่สามที่เลือก สร้างคำนำหน้า Homebrew และหากคุณเปิดตัวเลือกไว้ จะเพิ่มบรรทัดสภาพแวดล้อม shell ของ Homebrew ลงใน ~/.zprofile โปรแกรมติดตั้งแพ็กเกจอาจขอข้อมูลรับรองผู้ดูแลระบบและแก้ไขไฟล์ระบบหรือไฟล์ผู้ใช้นอก XHelpers Pro โปรดตรวจสอบทุกรายการที่เลือกและข้อกำหนดของ Apple, Homebrew, แพ็กเกจ, แอป และแบบอักษรที่ใช้บังคับ

การจับภาพหน้าจอ OCR คลิปบอร์ด การปักหมุด ชั้นวาง การคัดลอก การบันทึก และการแชร์ อาจประมวลผลหรือเปิดเผยข้อมูลลับที่ปรากฏบนหน้าจอหรืออยู่ในเอกสาร คุณมีหน้าที่ตรวจสอบว่ามีสิทธิ์จับ แปลง คัดลอก บันทึก หรือแชร์เนื้อหานั้น เมื่อคุณเลือกเมนูแชร์ของระบบ คลิปบอร์ด หรือแอปพลิเคชันอื่น ผู้รับที่เลือกสามารถได้รับเนื้อหา และข้อกำหนดกับหลักปฏิบัติด้านความเป็นส่วนตัวของผู้รับจะมีผล

ผลการตรวจสุขภาพระบบ OCR การแปล การแยกผู้พูด คำบรรยาย และผลการรู้จำหรือวินิจฉัยอื่นเป็นการทำงานอย่างดีที่สุด และอาจล่าช้า ไม่ครบถ้วน หรือไม่ถูกต้อง Mac Health ให้ข้อสังเกตเพื่อเป็นข้อมูลและตัวเลือกส่งต่อที่ปลอดภัย การเฝ้าดูทำงานเมื่อคุณเปิดใช้และขณะที่ซอฟต์แวร์ทำงานเท่านั้น และไม่ทำงานต่อหลังปิดแอป Mac Health ไม่ใช่หลักฐานของสาเหตุ การแก้ไขอัตโนมัติ หรือสิ่งทดแทนตัวตรวจสอบกิจกรรม ฝ่ายสนับสนุนทางเทคนิคที่มีคุณสมบัติ หรือคำแนะนำจากผู้เชี่ยวชาญ อย่าพึ่งพาซอฟต์แวร์สำหรับการใช้งานที่สำคัญต่อความปลอดภัย สำคัญต่อการช่วยการเข้าถึง การแพทย์ เหตุฉุกเฉิน กฎหมาย การเงิน หรือความเสี่ยงสูงอื่น

เมื่อคุณสั่งให้ซอฟต์แวร์เปิดเส้นทางหรือรายการในแอปพลิเคชันอื่น ข้อกำหนด หลักปฏิบัติด้านความเป็นส่วนตัว พฤติกรรมเครือข่าย และความเข้ากันได้ของแอปพลิเคชันนั้นจะมีผล Xintech ไม่ควบคุมแอปพลิเคชันหรือบริการของบริษัทอื่น

หากคุณกำหนดค่าผู้ให้บริการ AI คุณมีหน้าที่รับผิดชอบบัญชี ข้อมูลประจำตัว การเลือกโมเดล ข้อกำหนดผู้ให้บริการที่ใช้บังคับ ขีดจำกัดการใช้งาน และค่าใช้จ่าย บริการ AI อาจใช้งานไม่ได้และอาจสร้างผลลัพธ์ที่ไม่ถูกต้อง ไม่ครบถ้วน หรือเป็นอันตราย การเลือก AI เริ่มต้นไม่อนุญาตให้โมเดลอ่านไฟล์ เรียกใช้คำสั่ง หรือควบคุมคุณสมบัติซอฟต์แวร์ อย่าถือว่าผลลัพธ์ AI ใช้แทนคำแนะนำจากผู้เชี่ยวชาญหรือการตรวจสอบอย่างอิสระได้

ซอฟต์แวร์ไม่รวมหรือติดตั้ง Codex SDK, Claude Agent SDK หรือ CLI ของ SDK เหล่านั้น หากคุณเลือกการผสานรวมใด คุณมีหน้าที่ติดตั้งและดูแล SDK ที่เข้ากันได้ตรงรุ่นแยกต่างหากภายใต้ข้อกำหนดของผู้ให้บริการ การผสานรวม OpenAI Responses API ไม่ต้องใช้ SDK เอเจนต์ภายในเครื่อง

5. การอัปเดต บริการ และความพร้อมใช้งาน

Xintech อาจให้การอัปเดตแต่ไม่มีหน้าที่ต้องให้ การอัปเดตอาจอยู่ภายใต้ข้อตกลงนี้หรือข้อกำหนดฉบับปรับปรุงที่ให้มากับการอัปเดต

ในขอบเขตสูงสุดที่กฎหมายอนุญาต Xintech ไม่รับรองว่าซอฟต์แวร์ คุณสมบัติใด การอัปเดต การดาวน์โหลดหรือดาวน์โหลดซ้ำ ฟีดอัปเดต บริการเปิดใช้งานหรือตรวจสอบสิทธิ์ การผสานรวมของบริษัทอื่น หรือช่องทางจัดจำหน่าย จะพร้อมใช้งานต่อไปเป็นระยะเวลาใด Xintech อาจแก้ไข ระงับ ยกเลิก ลบ หรือหยุดจัดจำหน่ายซอฟต์แวร์หรือคุณสมบัติ การอัปเดต บริการ การดาวน์โหลด ช่องทางจัดจำหน่าย หรือทรัพยากรสนับสนุนที่เกี่ยวข้องได้ตลอดเวลา

คุณสมบัติซอฟต์แวร์บางอย่างอาจขึ้นอยู่กับ macOS, บริการ Apple, บริการหรือเครื่องมือของบริษัทอื่น การเชื่อมต่อเครือข่าย ความสามารถฮาร์ดแวร์ หรือสิทธิ์ความปลอดภัย คุณสมบัติบัญชีแบบเลือกใช้ยังขึ้นอยู่กับ Supabase การส่งอีเมล Apple, Google บริการบัญชีของ Xintech ความพร้อมใช้งานของเครือข่าย และบิลด์ซอฟต์แวร์ที่ลงลายเซ็นและรองรับ Xintech ไม่รับผิดชอบต่อการเปลี่ยนแปลง การหยุดทำงาน การนำออก ข้อจำกัด การตัดสินใจตรวจทาน หรือการยุติโดย Apple หรือบริษัทอื่น
