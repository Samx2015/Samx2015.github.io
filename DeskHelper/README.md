# DeskHelper Website

Source for the DeskHelper App Store website.

- Source copy: `/Users/sam/GitHub/HelperSuite/Websites/Sources/DeskHelper`
- Live GitHub Pages folder: `/Users/sam/GitHub/Samx2015.github.io/DeskHelper`
- Optional standalone mirror: `/Users/sam/GitHub/DeskHelper`
- Public URL: `https://xintechllc.com/DeskHelper/`

DeskHelper shares the same product family and visual system as DeskHelper Pro, but
this site is intentionally App Store-oriented:

- no Sparkle appcast or direct-download DMG
- no trial or license purchase copy
- no Auto Wi-Fi switching copy
- Finder context menus are described as the App Store-compatible Finder
  extension feature
- local `.safe` encryption/decryption is described as an App Store-compatible
  local Finder action
