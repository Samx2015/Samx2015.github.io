XTimers by Xintech LLC SMS 規約

この翻訳は便宜上提供されています。英語版が正式な版です。 English.

XTimers は Xintech LLC が運営しています。XTimers が SMS メッセージを送信するのは、サインイン中のユーザーが自分の アカウント電話番号として追加し、確認し、オプトインした電話番号に限られます。 現在の SMS プログラムは、アカウント電話番号の確認コードと、 ユーザーが自分用に作成してスケジュールしたタイマー/リマインダー SMS に 限定されます。XTimers はマーケティング SMS を送信せず、 ユーザーが任意の第三者宛てに SMS を送信することもできません。 XTimers SMS は双方向チャットまたは会話サービスではありません。 受信キーワードは STOP、HELP、START、YES のコンプライアンス処理にのみ 使用されます。

オプトイン

ユーザーは XTimers アプリ内で電話番号を入力し、事前に選択されていない チェックボックスを自分でオンにすることでオプトインします。チェックボックスの 文言は「XTimers by Xintech LLC から、この電話番号宛てに SMS 確認コードと、自分でスケジュールするリマインダーメッセージを受け取ることに 同意します。」です。オプトイン画面には、この SMS 規約、プライバシーポリシー、 標準のメッセージ料金およびデータ通信料に関する開示、STOP と HELP の説明、 メッセージ頻度の情報、ならびにマーケティングではないことの説明も表示されます。 同意は購入条件ではありません。 オプトイン証跡ページもご覧ください。 xintechllc.com/FlexibleTimers/ja/sms-opt-in.html。

メッセージの頻度

メッセージ頻度は状況によって異なります。XTimers は、ユーザーが 自分のアカウント電話番号の確認をリクエストしたときに確認メッセージを送信します。 XTimers がリマインダー SMS を送信するのは、確認済みの アカウント所有者がその SMS リマインダーを自分用に作成し、スケジュールした場合のみです。 ユーザーは SMS でチャット返信や任意のユーザー作成メッセージを XTimers に送信することはできません。

料金

標準のメッセージ料金およびデータ通信料が適用される場合があります。 これらの料金は携帯電話会社から請求され、お客様の負担となります。

オプトアウト

XTimers からの SMS メッセージをオプトアウトするには、STOP と返信してください。 STOP を送信すると、再度オプトインしない限り、XTimers はその電話番号への SMS メッセージ送信を停止します。

ヘルプ

ヘルプが必要な場合は HELP と返信してください。XTimers サポートにもお問い合わせいただけます。 xintechllc.com/FlexibleTimers/ja/support.html。

SMS キーワードと応答

STOP は、その電話番号を XTimers SMS からオプトアウトします。 想定される STOP 返信は「XTimers SMS からオプトアウトされました。 今後メッセージは送信されません。再度オプトインするには START と返信してください。」です。

HELP はサポート情報をリクエストします。想定される HELP 返信は 「XTimers はアカウント確認コードと、あなたが自分用にスケジュールした リマインダー SMS を送信します。ヘルプ: https://xintechllc.com/FlexibleTimers/support.html。 オプトアウトするには STOP と返信してください。」です。

START または YES は、ユーザーがそのアカウント電話番号についてすでにアプリで 同意済みの場合、以前にオプトアウトした電話番号を再度オプトインします。 想定される START 返信は「XTimers SMS メッセージに再度オプトインしました。 メッセージ頻度は状況によって異なります。オプトアウトするには STOP、ヘルプには HELP と 返信してください。」です。

携帯通信事業者の責任

携帯通信事業者は、メッセージの遅延または未配信について責任を負いません。
