Подтверждение согласия на SMS Flexible Timers by Xintech LLC

На этой странице описан процесс согласия на Flexible Timers SMS для проверки бесплатного номера Twilio. Сервис Flexible Timers управляется Xintech LLC. Конечная компания, показанная пользователям, - Flexible Timers by Xintech LLC. Flexible Timers SMS ограничен кодами подтверждения номера телефона учетной записи и SMS с таймерами/напоминаниями, созданными пользователем и отправляемыми только на собственный подтвержденный номер телефона учетной записи вошедшего в систему пользователя, выбравшего получение SMS. Flexible Timers не позволяет пользователям отправлять сообщения произвольным третьим лицам, не отправляет маркетинговые текстовые сообщения и не предоставляет двусторонний SMS-чат.

Порядок согласия

  1. Пользователь входит в систему Flexible Timers.
  2. Пользователь открывает информацию об учетной записи.
  3. Пользователь открывает раздел «Настроить SMS».
  4. Пользователь вводит собственный номер телефона.
  5. Флажок согласия на SMS не отмечен заранее.
  6. Пользователь явно устанавливает флажок согласия на SMS.
  7. Пользователь может открыть ссылки на Условия SMS и Политику конфиденциальности на одном и том же экране.
  8. Пользователь нажимает «Продолжить», чтобы запросить одноразовый код подтверждения.
  9. После подтверждения телефона и согласия на SMS пользователь может запланировать SMS-напоминание только на тот же подтверждённый номер телефона учётной записи, для которого дано согласие.

Текст согласия

Я согласен получать на этот номер телефона SMS-коды подтверждения и сообщения-напоминания от Flexible Timers от Xintech LLC, которые я планирую для себя. Может взиматься стандартная плата за сообщения и передачу данных. Для отказа ответьте STOP, для помощи — HELP. Частота сообщений может меняться. Flexible Timers не отправляет маркетинговые сообщения. Согласие не является условием покупки.

Примеры реальных сообщений

Код подтверждения Flexible Timers: 123456. Этот код истекает через 10 минут. Ответьте STOP, чтобы отказаться, или HELP, чтобы получить помощь.

Напоминание Flexible Timers. Вы запланировали это напоминание SMS на 16:00: Забрать ребенка на урок фортепиано после школы. Чтобы отказаться, ответьте STOP, а за помощью — HELP.

Ответы по ключевым словам

Входящие ключевые слова используются только для соблюдения требований и управления сообщениями для номера телефона учетной записи. Flexible Timers не принимает общие SMS-разговоры.

Ответ STOP: Вы отказались от участия в Flexible Timers SMS. Сообщения больше не будут отправляться. Ответьте START, чтобы снова выбрать участие.

Ответ на HELP: Flexible Timers отправляет коды подтверждения учётной записи и SMS-напоминания, которые вы планируете для себя. Помощь: https://xintechllc.com/FlexibleTimers/ru/support.html. Для отказа ответьте STOP.

Ответ START: Вы снова выбрали получение сообщений Flexible Timers SMS. Частота сообщений может различаться. Ответьте STOP, чтобы отказаться, или HELP, чтобы получить помощь.
