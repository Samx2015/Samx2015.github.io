Flexible Timers drivs av Xintech LLC. Flexible Timers kan endast skicka SMS-meddelanden till ett telefonnummer som en inloggad användare lägger till, verifierar och anmäler som sitt eget kontotelefonnummer. Det nuvarande SMS-programmet är begränsat till verifieringskoder för kontotelefonnummer och användarskapade timer- eller påminnelse-SMS som användaren schemalägger för sig själv. Flexible Timers skickar inte marknadsföringsmeddelanden och tillåter inte användare att skicka SMS till godtyckliga tredjepartsmottagare. Flexible Timers SMS är inte en tvåvägschatt eller samtalstjänst; inkommande sökord används endast för efterlevnad kring STOP, HELP, START och YES.

Samtycke

Användare anmäler sig i Flexible Timers-appen genom att ange sitt telefonnummer och aktivt markera en ruta som inte är förvald. Kryssrutan säger: "Jag samtycker till att ta emot SMS-verifieringskoder och påminnelsemeddelanden från Flexible Timers by Xintech LLC som jag schemalägger för mig själv på detta telefonnummer." På anmälningsskärmen visas även dessa SMS-villkor, sekretesspolicyn, information om standardavgifter för meddelanden och data, STOP- och HELP-instruktioner, information om meddelandefrekvens och text om att inga marknadsföringsmeddelanden skickas. Samtycke är inte ett villkor för köp. Se sidan med samtyckesbevis på xintechllc.com/FlexibleTimers/sv/sms-opt-in.html.

Meddelandefrekvens

Meddelandefrekvensen varierar. Flexible Timers skickar verifieringsmeddelanden när en användare begär verifiering av sitt eget kontotelefonnummer. Flexible Timers skickar SMS-påminnelser endast när den verifierade kontoägaren skapar och schemalägger påminnelsen för sig själv. Användare kan inte skicka chattsvar eller användarskrivna meddelanden till Flexible Timers via SMS.

Avgifter

Standardavgifter för meddelanden och data kan tillkomma. Dessa avgifter tas ut av din mobiloperatör och är ditt ansvar.

Avanmälan

Svara STOP för att avanmäla dig från SMS-meddelanden från Flexible Timers. Efter att du har skickat STOP slutar Flexible Timers skicka SMS-meddelanden till det telefonnumret, om du inte anmäler dig igen.

Hjälp

Svara HELP för hjälp. Du kan också kontakta Flexible Timers support på xintechllc.com/FlexibleTimers/sv/support.html.

SMS-nyckelord och svar

STOP avanmäler telefonnumret från Flexible Timers SMS. Det förväntade STOP-svaret är: "Du har avanmält dig från Flexible Timers SMS. Inga fler meddelanden kommer att skickas. Svara START för att anmäla dig igen."

HELP begär supportinformation. Det förväntade HELP-svaret är: "Flexible Timers skickar kontoverifieringskoder och SMS-påminnelser som du schemalägger för dig själv. Hjälp: https://xintechllc.com/FlexibleTimers/support.html. Svara STOP för att avanmäla dig."

START eller YES anmäler ett tidigare avanmält telefonnummer igen efter att användaren redan har gett samtycke i appen för det kontotelefonnumret. Det förväntade START-svaret är: "Du har anmält dig igen till Flexible Timers SMS-meddelanden. Meddelandefrekvensen varierar. Svara STOP för att avanmäla dig, HELP för hjälp."

Operatörsansvar

Trådlösa operatörer är inte ansvariga för försenade eller ej levererade meddelanden.
