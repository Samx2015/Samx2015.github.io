Diese Seite dokumentiert den Flexible Timers SMS Opt-in-Ablauf für Twilio gebührenfreie Verifizierung. Flexible Timers wird von Xintech LLC betrieben. Die Das Endgeschäft, das den Benutzern angezeigt wird, ist Flexible Timers by Xintech LLC. Flexibel Timer SMS ist auf Konto-Telefonbestätigungscodes und beschränkt Vom Benutzer erstellter Timer/Erinnerung SMS, der nur an einen angemeldeten Benutzer gesendet wird verifizierte, für das Konto aktivierte Telefonnummer. Flexible Timers lässt nicht zu Benutzer senden Nachrichten an beliebige Dritte, senden keine Marketingtexte Nachrichten und bietet keinen bidirektionalen SMS-Chat.

Opt-In-Flow

  1. Der Benutzer meldet sich bei Flexible Timers an.
  2. Der Benutzer öffnet die Kontoinformationen.
  3. Der Benutzer öffnet „SMS einrichten“.
  4. Der Benutzer gibt seine eigene Telefonnummer ein.
  5. Das Kontrollkästchen „Zustimmung SMS“ ist nicht vorausgewählt.
  6. Der Benutzer aktiviert das Kontrollkästchen „Zustimmung SMS“ positiv.
  7. Der Benutzer kann die SMS-Nutzungsbedingungen und Datenschutzrichtlinien-Links auf demselben Bildschirm öffnen.
  8. Der Benutzer klickt auf „Weiter“, um einen einmaligen Bestätigungscode anzufordern.
  9. Nachdem das Telefon überprüft und aktiviert wurde, kann der Benutzer eine Erinnerung SMS planen nur an dieselbe verifizierte, für das Konto aktivierte Telefonnummer.

Einwilligungssprache

Ich bin damit einverstanden, SMS-Verifizierungscodes und Erinnerungsnachrichten von zu erhalten Flexible Timers by Xintech LLC, die ich an diesem Telefon für mich selbst terminiere Nummer. Es können Standard-Nachrichten- und Datentarife anfallen. Antworten Sie auf STOP, um sich abzumelden und HELP für Hilfe. Die Häufigkeit der Nachrichten variiert. Flexible Timers wird das nicht tun Marketingtexte versenden. Die Zustimmung ist keine Kaufbedingung.

Beispiel-Produktionsnachrichten

Flexible Timers-Verifizierungscode: 123456. Dieser Code läuft in 10 ab Minuten. Antworten Sie auf STOP, um sich abzumelden, und auf HELP, um Hilfe zu erhalten.

Flexible Timers-Erinnerung: Sie haben diese SMS-Erinnerung für 16:00 Uhr geplant: Holen Sie Ihr Kind für den Klavierunterricht nach der Schule ab. Antworten Sie mit STOP, um sich abzumelden, HELP um Hilfe.

Keyword-Antworten

Eingehende Schlüsselwörter werden nur für Compliance- und Konto-Telefonnachrichten verwendet Kontrollen. Flexible Timers akzeptiert keine allgemeinen SMS-Konversationen.

STOP-Antwort: Sie haben sich von Flexible Timers SMS abgemeldet. Keine Nachrichten mehr wird verschickt. Antworten Sie auf START, um sich erneut anzumelden.

HELP-Antwort: Flexible Timers sendet Kontobestätigungscodes und Erinnerung SMS, die Sie selbst planen. Hilfe: https://xintechllc.com/FlexibleTimers/support.html. Antworten Sie auf STOP, um sich abzumelden.

START-Antwort: Sie haben sich wieder für den Empfang von Flexible Timers SMS-Nachrichten entschieden. Die Häufigkeit der Nachrichten variiert. Antworten Sie auf STOP, um sich abzumelden, und auf HELP, um Hilfe zu erhalten.
