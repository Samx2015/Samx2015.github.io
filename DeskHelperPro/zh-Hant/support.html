DeskHelper Pro 支援

如需支援、隱私問題、錯誤、授權問題或想法，請寄信至 admin@xintechllc.com.

你也可以在 App 選單中使用「回報問題」、「建議功能」或「傳送回饋」。這些項目會開啟電子郵件草稿，讓你在送出前檢查所有內容。

回報問題時

回報問題時，請包含：

  • 發生了什麼，以及你原本預期會發生什麼。
  • 你的 macOS 版本和 Mac 型號（如果知道）。
  • MacBook 螢幕是鏡像還是延伸。
  • DeskHelper Pro 版本與建置編號。
  • 重現問題的步驟。

錯誤回報草稿可能包含簡短診斷說明。請移除任何你不想傳送的內容。

Finder 內容選單

DeskHelper Pro 使用內建 Finder 延伸功能。macOS 控制該延伸功能是否啟用。你可以從 DeskHelper Pro 選單開啟權限與設定流程，或在系統設定的「登入項目與延伸功能」中查看。

  • 如果 Finder 內容選單沒有出現，請確認 DeskHelper Pro 正從「應用程式」執行。
  • 開啟 DeskHelper Pro 選單並選擇「設定 Finder 內容選單」。
  • 如果 Finder 動作無法開啟或建立項目，macOS 可能需要你核准資料夾存取。
  • 對於受保護的 macOS 位置，請從 DeskHelper Pro 開啟「完整磁碟存取權」設定並啟用 App。

Safes

使用 Finder 內容選單可將選取的本機檔案或資料夾加密成 .safe 檔案、加入現有 Safe，或將 Safe 解密回資料夾。密碼只用於你啟動的動作，DeskHelper Pro 不會儲存。

授權與更新

  • DeskHelper Pro 包含 14 天試用。
  • 授權啟用使用 Lemon Squeezy，並將授權金鑰儲存在 Mac 的鑰匙圈中。
  • 啟用自動檢查或選擇「檢查更新」時，會透過 Sparkle 檢查更新。

注意事項

  • DeskHelper Pro 會出現在 macOS 選單列中，不顯示 Dock 圖示。
  • Auto Wi-Fi Switch 可能需要位置權限，因為 macOS 會保護 Wi-Fi 網路名稱。
  • 鍵盤背光控制取決於 Mac 硬體支援。
  • 閱讀 DeskHelper Pro 隱私政策 了解詳情。
