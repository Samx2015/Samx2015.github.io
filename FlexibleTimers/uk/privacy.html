Політика конфіденційності Flexible Timers by Xintech LLC

Flexible Timers управляється Xintech LLC. Flexible Timers використовує обліковий запис інформація для надання таймера, нагадування, облікового запису, синхронізації, звіту, і функції повідомлень. Зараз Flexible Timers надсилає звіти електронною поштою та повідомлення електронної пошти лише на адресу електронної пошти власного облікового запису користувача. Ця політика також описує умови конфіденційності SMS для телефону облікового запису перевірка та створені користувачем нагадування SMS, надіслані лише власним користувачам підтверджений номер телефону облікового запису.

Інформація, зібрана для електронної пошти

Коли користувач, який увійшов у систему, запитує підтвердження, звіт, відгук або нагадування електронною поштою, Flexible Timers може обробляти електронну пошту облікового запису користувача адреса, вміст повідомлення, дані таймера/звіту, необхідні для запиту, а також метадані доставки, необхідні для роботи, усунення несправностей і захисту служби.

Інформація, зібрана для SMS

Коли користувач, який увійшов у систему, додає власний номер телефону облікового запису для SMS, Flexible Timers може зберігати номер телефону, статус згоди, згоду джерело, версія тексту згоди, формулювання згоди, URL-адреса умов SMS, конфіденційність URL-адреса політики, позначка часу, статус перевірки, створене користувачем повідомлення-нагадування вміст, запланований час нагадування та необхідні метадані доставки повідомлення працювати та перевіряти програму SMS.

Як використовується інформація SMS

Інформація SMS використовується для перевірки номера телефону облікового запису користувача, надсилати нагадування SMS, що користувач планує для себе, підтримувати згоду і відмовлятися від записів, запобігати зловживанням, вирішувати проблеми з доставкою та дотримуватися вимоги перевізника та законодавства.

Жодного маркетингового продажу чи обміну

Flexible Timers не продає дані для реєстрації SMS. Flexible Timers не робить поділитися даними про згоду, номерами телефонів або текстовими повідомленнями третьої особи сторони або філії для маркетингових або рекламних цілей.

Постачальники послуг

Flexible Timers може використовувати постачальників послуг, включаючи постачальників SMS, щоб доставляти повідомлення підтвердження, доставляти заплановане користувачем нагадування SMS та керувати послугою. Ці постачальники можуть обробляти інформацію SMS лише як необхідні для надання послуги обміну повідомленнями.

Відмова

Користувачі можуть відповісти STOP, щоб відмовитися від повідомлень SMS. Користувачі можуть відповісти на HELP допомогти.
