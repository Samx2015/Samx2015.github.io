จอแสดงผลและหน้าต่าง

จัดจอแสดงผลและหน้าต่างให้เข้ากับวิธีทำงานของคุณ โดยไม่ต้องมีแอปเสริมอีกตัว

  • ทำงานบนจอใหญ่เพียงจอเดียว: ดับจอในตัวของ MacBook ขณะสะท้อนภาพ และหรี่ทุกจอจนกว่าจะกดปุ่ม
  • ห้าตัวควบคุมในเมนูเดียว: ความสว่าง คอนทราสต์ ไฟแป้นพิมพ์ และธีม macOS โดยไม่ต้องไล่หาในการตั้งค่าระบบ
  • ได้ข้อความคมชัดในขนาดที่ต้องการบนจอภายนอกทุกจอ: พรีเซ็ต HiDPI และความละเอียดแบบกำหนดเอง พร้อมตัวจับเวลาที่เปลี่ยนกลับให้อัตโนมัติหากตั้งค่าผิดพลาด
  • จัดทุกหน้าต่างเข้าที่ด้วยปุ่มลัดเดียว: แบ่งครึ่งจอ แบ่งสี่ส่วนตามต้องการ จัดกึ่งกลาง ขยายหน้าต่างให้ใหญ่สุด หรือย้ายไปจอถัดไป และเรียกคืนทั้งรูปแบบการจัดวางหลังถอดสาย
  • เห็นหน้าต่างที่ใช้งานอยู่เสมอ แม้บนโต๊ะที่กว้าง และให้ Mac ตื่นอยู่เสมอนานเท่าที่การดาวน์โหลดหรือการบรรยายต้องใช้

หน้าจอ ข้อความ และไฟล์

ลากครั้งเดียวก็จับข้อความ ลิงก์ สี หรือวัดขนาดจากสิ่งที่อยู่บนหน้าจอได้ ส่วนไฟล์บนดิสก์ก็มีเครื่องมือแก้ไขหรือแปลงไฟล์ขนาดเล็กที่เหมาะกับงาน

  • ไม่ต้องพิมพ์ข้อความบนหน้าจอซ้ำ: ลากครอบข้อความแล้วคัดลอก เปิดลิงก์ แปล (macOS 15 ขึ้นไป) หรือฟังการอ่านออกเสียง สแกนรหัส QR และบาร์โค้ดได้ด้วยวิธีเดียวกัน
  • เก็บข้อมูลอ้างอิงไว้ให้เห็นขณะทำงาน: ปักหมุดพื้นที่หน้าจอให้ลอยเหนือทุกหน้าต่าง เก็บภาพที่จับไว้บนชั้นวางหน้าจอ วัดขนาดหรือเลือกสี หรือใส่คำอธิบายประกอบภาพแล้วส่งต่อ
  • ไม่พลาดสิ่งที่เคยคัดลอก: ประวัติคลิปบอร์ดที่ค้นหาและปักหมุดได้ พร้อมโปรแกรมแก้ไขข้อความที่มีตัวเรียกดูไฟล์ การเน้นไวยากรณ์โค้ด และภาพตัวอย่าง Markdown ที่แสดงแผนภาพ Mermaid ได้
  • จัดข้อความที่ยุ่งเหยิงโดยไม่ต้องเขียนสคริปต์: จัดช่องว่าง แก้ตัวอักษรเพี้ยน ถอดรหัส HTML, URL และ Base64 จัดรูปแบบ JSON ปิดบังข้อมูลติดต่อ หรือเปลี่ยนบรรทัดข้อความเป็นตาราง ทั้งหมดใช้โมเดลของ Apple ที่ทำงานบนอุปกรณ์
  • จัดการรูปภาพและ PDF โดยไม่ต้องเปิดห้าแอป: ปรับขนาด ใส่คำอธิบายประกอบ และส่งออกหลายไฟล์พร้อมกัน รวมไฟล์ เรียงหน้าใหม่ ปลดล็อก หรือสร้าง PDF และเปิดไฟล์ข้อความหรือไบนารีขนาดใหญ่ที่โปรแกรมแก้ไขอื่นรับไม่ไหว

การใช้งาน AI

รวมโควตาที่เหลือของทุกบริการ AI ที่คุณสมัครไว้ในที่เดียว รู้ก่อนใช้จนหมด

  • ดูทุกบัญชีได้ในพริบตา: เทียบโควตารายสัปดาห์ที่เหลือ เวลารีเซ็ตครั้งถัดไป และจำนวนครั้งที่ยังรีเซ็ตขีดจำกัดได้ของแต่ละบัญชี Codex และ Claude ที่เชื่อมต่อไว้
  • ดูได้โดยไม่ต้องเปิดหน้าต่าง: วางตัวชี้เหนือมาตรวัด AI ในเมนูเพื่อดูการ์ดข้อมูลทุกบัญชี หรือปักหมุดบัญชีที่ใช้บ่อยที่สุดไว้บนแถบเมนู
  • สิบเอ็ดบริการในแดชบอร์ดเดียว: Codex, Claude, Grok, API ของ OpenAI, Anthropic และ xAI, Gemini, GitHub Copilot, Cursor, OpenRouter และ DeepSeek
  • ข้อมูลการใช้งานยังเป็นของคุณ: รวบรวมข้อมูลบน Mac เครื่องนี้ผ่าน CodexBar ที่มาพร้อมแอป โดยแต่ละรายการจะเก็บเวลาที่บันทึกจากแหล่งข้อมูลไว้

ขอขอบคุณ Peter Steinberger สำหรับ CodexBarCLI.

Finder ตู้เซฟ และไฟล์บีบอัด

งานไฟล์ที่ทำวันละสิบรอบ จัดการได้จากเมนูคลิกขวาที่คุณใช้อยู่แล้ว

  • ไม่ต้องอ้อมไปหลายขั้นตอน: สร้างไฟล์หรือโฟลเดอร์ตรงที่คุณอยู่ คัดลอกพาธ วางหรือย้ายรายการที่เลือก และเปิดไฟล์ในแอปที่รองรับ 40+ แอป ตั้งแต่ Terminal และ VS Code ไปจนถึง Codex และ Claude
  • ล็อกไฟล์ส่วนตัวในไม่กี่วินาที: เปลี่ยนรายการที่เลือกเป็นตู้เซฟเข้ารหัส, 7z, ZIP หรือ DMG ได้ในกล่องโต้ตอบเดียว พร้อมรหัสผ่านที่มีคุณเท่านั้นที่รู้
  • เพิ่มไฟล์ในตู้เซฟได้เรื่อย ๆ โดยไม่ต้องบรรจุใหม่ และนำออกเฉพาะรายการที่ต้องการ
  • เปิดไฟล์บีบอัดที่ใครส่งมาให้ก็ได้ ตั้งแต่ zip ถึง rar รวมถึงไฟล์ที่มีรหัสผ่าน โดยไม่ต้องติดตั้งโปรแกรมแตกไฟล์เพิ่ม
  • อ่าน Markdown ได้ด้วยการกดสเปซบาร์ ใน Finder และเริ่มถอนการติดตั้งอย่างหมดจดจากเมนูคลิกขวาเดียวกัน

ตัวชี้และแป้นพิมพ์

ปรับเมาส์ แทร็คแพด และแป้นพิมพ์ทุกชิ้นให้ใช้งานได้พอดีมือ และคงค่านั้นไว้

  • เลื่อนตัวชี้ได้ตรงใจ: ปรับความไวและอัตราเร่งแยกตามอุปกรณ์ หรือปิดอัตราเร่งทั้งหมดเพื่อให้ตัวชี้เคลื่อนตามมืออย่างสม่ำเสมอ
  • เลื่อนได้เหมาะกับแต่ละอุปกรณ์ ด้วยความเร็ว อัตราเร่ง และทิศทางที่ตั้งแยกตามเมาส์หรือแทร็คแพด ให้ล้อเลื่อนกับแทร็คแพดไม่ต้องใช้ค่าที่ขัดกันอีก
  • เปลี่ยนปุ่มว่างบนแป้นพิมพ์หรือเมาส์ให้เป็นปุ่มลัดที่ใช้บ่อยที่สุด ให้ Caps Lock ทำได้สองหน้าที่ หรือเพิ่มปุ่ม Hyper ที่ไม่ชนกับปุ่มลัดของแอป
  • ใช้ทุกเครื่องมือได้จากแป้นพิมพ์: ตั้งปุ่มลัดให้ 67 คำสั่งได้ในหน้าต่างปุ่มลัดทั่วระบบเพียงแห่งเดียว

เสียง เพลง และคำบรรยาย

ควบคุมเสียงของแต่ละแอป รวมทุกแหล่งไว้ในที่เดียว และอ่านคำพูดจากทุกแอป

  • ไม่ต้องคอยปรับเสียงทุกครั้งที่เริ่มคุยสาย: ตั้งระดับเสียงและปิดเสียงแยกแต่ละแอป เร่งเสียงแอปที่เบาได้สูงสุด 200% และปรับแต่งด้วยเอฟเฟกต์เสียงรายแอป
  • เพลย์ลิสต์รวมหลายแหล่งในคลังเดียว: รวม Apple Music เพลงจาก YouTube และเสียงกับวิดีโอในเครื่องไว้ในเพลย์ลิสต์เดียวกัน พร้อมตัวกรองที่บันทึกไว้ซึ่งใช้ได้ทั่วทั้งคลังของคุณ
  • เครื่องเล่นที่ไม่หนักเครื่องสำหรับไฟล์ที่เพิ่งดาวน์โหลด: ใช้คิวร่วมกัน พร้อมเครื่องเล่นวิดีโอที่ปรับความเร็ว เล่นวน และแสดงเหนือหน้าต่างอื่นได้ แยกเสียงจากวิดีโอได้ในคลิกเดียว
  • ติดตามทุกการประชุม สตรีม หรือวิดีโอในภาษาของคุณ: คำบรรยายสดถอดเสียงและแปลเสียงจากแอปหนึ่งแอปบนอุปกรณ์ พร้อมโหมดเฉพาะคำบรรยายและสีแยกผู้พูด (macOS 26.4 ขึ้นไป)

สุขภาพ Mac พื้นที่จัดเก็บ และแอป

หาสาเหตุที่ Mac ช้าหรือพื้นที่เต็ม แล้วแก้ไขจากข้อมูลที่เห็นบนหน้าจอ โดยไม่มีอะไรถูกลบลับหลังคุณ

  • ได้คำตอบชัด ๆ ว่า “ทำไม Mac ของฉันจึงช้า”: ผลวิเคราะห์พร้อมสาเหตุ และเครื่องวัดสุขภาพหน่วยความจำที่เฝ้าดูภาระหน่วยความจำและการใช้สวอปก่อนเครื่องจะอืด
  • ดูทุกอย่างที่เริ่มทำงานพร้อม Mac รวมถึงลายเซ็น และปิดเฉพาะรายการของคุณ ดูการตั้งค่า macOS หลายสิบรายการในรูปแบบการ์ดที่แสดงค่าที่บันทึกอยู่ในขณะนี้
  • เรียกคืนพื้นที่ได้อย่างมั่นใจ: มีคำแนะนำการเรียกคืนพื้นที่และแผนที่พื้นที่จัดเก็บ แผนภูมิทรีแมปแสดงว่าพื้นที่ดิสก์ถูกใช้ไปกับอะไร และค้นหาไฟล์ซ้ำด้วยเครื่องมือ “ไฟล์ซ้ำและไฟล์รก”
  • ถอนแอปให้หมดจด: ตรวจรายการไฟล์ก่อนย้ายสิ่งใด ค้นหาไฟล์ตกค้างจากแอปที่ลบไปนานแล้ว และส่งออกรายงานการล้างข้อมูลได้ ตั้งค่า Mac เครื่องใหม่ด้วยเครื่องมือ “ติดตั้งแอปและเครื่องมือนักพัฒนา” และ “จัดการแบบอักษร”
  • รู้ว่าเป็นที่ Wi-Fi หรือเว็บไซต์: เครื่องมือคุณภาพเครือข่ายวัดการเชื่อมต่อที่คุณใช้อยู่ และการสลับ Wi-Fi อัตโนมัติจะเปลี่ยนไปใช้เครือข่ายที่บันทึกไว้ซึ่งสัญญาณแรงกว่าเมื่อสัญญาณอ่อนลง

  • ข้อเสนอแนะจะเปิดเป็นอีเมลฉบับร่างให้คุณอ่านก่อนส่ง
