Flexible Timers by Xintech LLC SMS 條款

本翻譯僅為方便閱讀提供。英文版本為權威版本。 English.

Flexible Timers 由 Xintech LLC 營運。Flexible Timers 只會向登入使用者 新增、驗證並選擇作為自己帳戶電話號碼的號碼傳送 SMS 訊息。 目前的 SMS 計畫僅包括帳戶電話驗證碼，以及使用者為自己建立和 安排的計時器/提醒 SMS。Flexible Timers 不傳送行銷簡訊，也不允許 使用者向任意第三方收件人傳送 SMS。Flexible Timers SMS 不是雙向 聊天或對話服務；入站關鍵字僅用於 STOP、HELP、START 和 YES 合規處理。

選擇加入

使用者在 Flexible Timers 應用程式中輸入電話號碼，並主動勾選預設 未勾選的核取方塊，即表示選擇加入。核取方塊文字為：「我同意接收 來自 Flexible Timers by Xintech LLC 的 SMS 驗證碼，以及我在此電話號碼上 為自己安排的提醒訊息。」選擇加入畫面也會顯示這些 SMS 條款、 隱私權政策、標準訊息和資料費率說明、STOP 和 HELP 說明、訊息頻率 資訊以及非行銷說明。同意不是購買條件。 請參閱選擇加入證據頁面： xintechllc.com/FlexibleTimers/zh-Hant/sms-opt-in.html。

訊息頻率

訊息頻率各不相同。使用者請求驗證自己的帳戶電話號碼時，Flexible Timers 會傳送驗證訊息。只有經過驗證的帳戶所有者建立並為自己安排 SMS 提醒時，Flexible Timers 才會傳送提醒。使用者不能透過 SMS 傳送 聊天回覆，也不能透過 SMS 向 Flexible Timers 傳送自訂訊息。

費用

可能適用標準訊息和資料費率。相關費用由您的行動電信業者收取， 並由您承擔。

選擇退出

回覆 STOP 可選擇退出來自 Flexible Timers 的 SMS 訊息。傳送 STOP 後， Flexible Timers 將停止向該電話號碼傳送 SMS 訊息， 除非您再次選擇加入。

幫助

回覆 HELP 尋求協助。您也可以聯絡 Flexible Timers 支援： xintechllc.com/FlexibleTimers/zh-Hant/support.html。

SMS 關鍵字和回應

STOP 會使該電話號碼退出 Flexible Timers SMS。預期的 STOP 回覆是： 「您已選擇退出 Flexible Timers SMS。不會再傳送更多訊息。回覆 START 以再次選擇加入。」

HELP 請求支援資訊。預期的 HELP 回應是： 「Flexible Timers 會傳送帳戶驗證碼，以及您為自己安排的 SMS 提醒。 協助：https://xintechllc.com/FlexibleTimers/support.html。回覆 STOP 選擇退出。」

如果使用者已經在應用程式中為該帳戶電話提供過同意，START 或 YES 會恢復 SMS。預期的 START 回覆是：「您已重新選擇加入 Flexible Timers SMS 訊息。訊息頻率各不相同。回覆 STOP 選擇退出，回覆 HELP 取得協助。」

承運人責任

無線運營商對延遲或未送達的訊息不承擔任何責任。

隱私

請參閱 Flexible Timers 隱私權政策： xintechllc.com/FlexibleTimers/zh-Hant/privacy.html。
