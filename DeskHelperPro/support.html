DeskHelper Pro Support

For support, privacy questions, bugs, license questions, or ideas, email admin@xintechllc.com.

You can also use Report a Bug, Suggest a Feature, or Send Feedback in the app menu. These items open an email draft so you can review everything before sending it.

When Reporting an Issue

When reporting an issue, please include:

  • What happened and what you expected to happen.
  • Your macOS version and Mac model, if known.
  • Whether the MacBook screen was mirrored or extended.
  • The DeskHelper Pro version and build number.
  • The steps that reproduce the issue.

Bug report drafts may include a short diagnostic note. Remove anything you do not want to send.

Finder Context Menus

DeskHelper Pro uses a bundled Finder extension. macOS controls whether that extension is enabled. You can open the permission and settings flow from the DeskHelper Pro menu, or open System Settings and look under Login Items & Extensions.

  • If Finder context menus do not appear, make sure DeskHelper Pro is running from Applications.
  • Open DeskHelper Pro's menu and choose Configure Finder context menus.
  • If a Finder action cannot open or create an item, macOS may need you to approve folder access.
  • For protected macOS locations, open Full Disk Access settings from DeskHelper Pro and enable the app there.

Safes and Secure Pocket

Use Finder context menus to encrypt selected local files or folders into a .safe file, add selected items to an existing Safe, or decrypt a Safe back into a folder. Passwords are used only for the action you start and are not stored by DeskHelper Pro.

Secure Pocket stores private notes, clipboard snippets, and small files in a local encrypted vault. DeskHelper Pro does not upload, transmit, or log Secure Pocket contents or passwords.

License and Updates

  • DeskHelper Pro includes a 14-day trial.
  • License activation uses Lemon Squeezy and stores the license key in your Mac's Keychain.
  • Updates are checked through Sparkle when automatic update checks are enabled or when you choose Check for Updates.

Notes

  • DeskHelper Pro appears in the macOS menu bar and does not show a Dock icon.
  • Auto Wi-Fi Switch may require Location permission because macOS protects Wi-Fi network names.
  • Keyboard backlight control depends on Mac hardware support.
  • Read the DeskHelper Pro Privacy Policy for details.
