DeskHelper Pro सहायता

सहायता, गोपनीयता प्रश्न, बग, लाइसेंस प्रश्न या विचारों के लिए ईमेल करें admin@xintechllc.com.

आप ऐप मेनू में Report a Bug, Suggest a Feature या Send Feedback भी इस्तेमाल कर सकते हैं। ये ईमेल ड्राफ्ट खोलते हैं ताकि भेजने से पहले आप सब कुछ देख सकें।

समस्या रिपोर्ट करते समय

कृपया शामिल करें:

  • क्या हुआ और आप क्या उम्मीद कर रहे थे।
  • macOS संस्करण और Mac मॉडल, यदि पता हो।
  • MacBook स्क्रीन मिरर थी या एक्सटेंडेड।
  • DeskHelper Pro संस्करण और build नंबर।
  • समस्या दोहराने के चरण।

बग रिपोर्ट ड्राफ्ट में छोटा डायग्नोस्टिक नोट हो सकता है। जो नहीं भेजना चाहते उसे हटा दें।

Finder context menus

DeskHelper Pro bundled Finder extension का उपयोग करता है। macOS तय करता है कि extension सक्षम है या नहीं। आप DeskHelper Pro मेनू से permission flow खोल सकते हैं या System Settings में Login Items & Extensions देख सकते हैं।

  • यदि Finder context menus नहीं दिखते, सुनिश्चित करें कि DeskHelper Pro Applications से चल रहा है।
  • DeskHelper Pro मेनू खोलें और Configure Finder context menus चुनें।
  • यदि Finder action कोई item खोल या बना नहीं सकता, macOS folder access माँग सकता है।
  • Protected macOS locations के लिए DeskHelper Pro से Full Disk Access settings खोलें और app सक्षम करें।

Safes और Secure Pocket

Finder context menus से चुनी हुई local files या folders को .safe file में encrypt करें, मौजूदा Safe में items जोड़ें या Safe को folder में decrypt करें। Passwords केवल शुरू की गई action के लिए इस्तेमाल होते हैं और DeskHelper Pro उन्हें store नहीं करता।

Secure Pocket private notes, clipboard snippets और छोटे files को local encrypted vault में रखता है। DeskHelper Pro Secure Pocket content या passwords upload, transmit या log नहीं करता।

लाइसेंस और अपडेट

  • DeskHelper Pro में 14 दिन का trial शामिल है।
  • License activation Lemon Squeezy का उपयोग करता है और key को Mac Keychain में रखता है।
  • Automatic checks चालू हों या Check for Updates चुनें तो Sparkle से updates check होते हैं।

नोट्स

  • Keyboard backlight control Mac hardware support पर निर्भर करता है।
