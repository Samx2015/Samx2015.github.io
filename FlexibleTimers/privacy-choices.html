XTimers Privacy Choices

XTimers provides controls for account data, synchronization, automatic activity tracking, reports, and SMS. This page explains where to find those controls.

Delete an XTimers Account

In XTimers, open the account controls while signed in and choose Delete Account. Confirm the request with the current password. This permanently deletes the server account and removes the signed-in account data from that Mac.

Account deletion removes active account-owned identity, timer, snapshot, custom-sound, feedback, reminder, message, and push-registration data. Separately maintained request logs, IP information, security records, and diagnostic submissions may remain when needed for security, troubleshooting, legal compliance, or service administration, as described in the Privacy Policy.

Manage Synchronization

Core timers can be used without an account. Account synchronization is used only when the user signs in. A user can stop future account synchronization by signing out, or permanently remove the server account by using Delete Account.

Manage Automatic Activity Tracking

Automatic application tracking can be enabled or disabled in XTimers settings. Website-hostname tracking is available only in the separately distributed XTimers Pro edition, where browser integration can also be enabled or disabled. Activity records stay on the Mac unless the user explicitly emails or publishes a report containing selected activity information.

Manage Online Reports

When creating an online report link, choose an expiration of 1, 7, 30, 90, or 365 days. The link stops working after that expiration. To avoid uploading report content, use local copy or export options instead of email or online publishing.

SMS Choices

SMS features require a verified phone number and affirmative consent. Reply STOP to opt out of SMS messages or HELP for help. Deleting the account also removes the active account phone and SMS configuration, subject to records that must be retained for carrier, legal, security, or abuse-prevention purposes.

Feedback Choices

XTimers offers separate choices to send feedback anonymously or attach it to the signed-in account. Ordinary network request metadata may still be recorded when anonymous feedback is submitted.

Contact

For a privacy question or request that cannot be completed in the app, see xintechllc.com/XTimers/support.html.
