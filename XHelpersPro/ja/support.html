XHelpers Pro サポート

サポート、プライバシー、バグ、ライセンス、アイデアについては、次のアドレスにメールしてください： admin@xintechllc.com.

App メニューの「バグを報告」「機能を提案」「フィードバックを送信」も使用できます。これらは送信前に内容を確認できるメール下書きを開きます。

問題を報告するとき

問題を報告するときは、次の情報を含めてください：

  • 何が起きたか、何が起きると期待していたか。
  • わかる場合は macOS バージョンと Mac モデル。
  • MacBook 画面がミラーリングか拡張か。
  • XHelpers Pro のバージョンとビルド番号。
  • 問題を再現する手順。

バグ報告の下書きには短い診断メモが含まれる場合があります。送信したくない内容は削除してください。

Finder コンテキストメニュー

XHelpers Pro は同梱の Finder 拡張を使用します。その拡張を有効にするかどうかは macOS が管理します。XHelpers Pro メニューから権限と設定の流れを開くか、システム設定の「ログイン項目と機能拡張」を確認してください。

  • Finder コンテキストメニューが表示されない場合は、XHelpers Pro が「アプリケーション」から実行されていることを確認してください。
  • XHelpers Pro メニューを開き、「Finder コンテキストメニューを設定」を選択します。
  • Finder 操作が項目を開いたり作成したりできない場合、macOS がフォルダアクセスの承認を求めることがあります。
  • 保護された macOS の場所では、XHelpers Pro からフルディスクアクセス設定を開いて App を有効にしてください。

Safes

Finder コンテキストメニューを使って、選択したローカルファイルやフォルダを .safe ファイルに暗号化したり、既存の Safe に追加したり、Safe をフォルダへ復号できます。パスワードは開始した操作だけに使用され、XHelpers Pro には保存されません。

ライセンスとアップデート

  • XHelpers Pro には 14 日間の試用期間があります。
  • ライセンスの有効化には Lemon Squeezy を使用し、ライセンスキーは Mac のキーチェーンに保存されます。
  • 自動更新確認が有効な場合、または「アップデートを確認」を選んだ場合、Sparkle で更新を確認します。

Xin アカウントとサインイン

Xin アカウントは任意です。すべてのローカルツール、14 日間の試用期間、ローカルの Pro 有効化は、サインアウトした状態でも、この Mac がオフラインでも動作します。アカウントサービスが利用できない場合、XHelpers Pro はアカウントウインドウでそのことを知らせ、アプリのそれ以外の部分は引き続き動作します。

次の 5 つの用語はそれぞれ異なるものを指しており、互いに置き換えることはできません。

  • サインイン ID — 認証に使用するメール、Google、または Apple の ID です。
  • Xin アカウント — 製品のメンバーシップを保持する Xintech のアカウントです。
  • XHelpers メンバーシップ — そのアカウントを XHelpers に登録したものです。
  • ローカルの有効化 — この Mac で有効化したライセンスキーで、ローカルの Pro 機能を使えるようにするものです。
  • サーバー利用権 — XHelpers メンバーシップに対してサーバー上に記録された有料アクセスです。

いずれかを作成しても、次のものが作成されることはありません。サインインしても Xin アカウントは作成されず、Xin アカウントがあっても XHelpers に登録されるわけではなく、どちらもこの Mac でライセンスを有効化するものではありません。

サインイン方法ごとに、復旧の手順は異なります。

  • パスワードによるサインアップ — サインインする前に確認メールでアドレスを確認し、届かない場合は「コードを再送信」を使用してください。
  • パスワードの復旧 — 復旧メッセージを要求し、この Mac で開いてから、表示されるウインドウで新しいパスワードを設定します。復旧を要求しただけではサインインした状態にはなりません。
  • サインインコード — コードを要求し、有効期限が切れる前に入力してください。コードは 1 回限り有効です。別のサインインをやり直すのではなく、「サインインコードを再送信」を選んでください。
  • Google — ブラウザでの手順を完了して XHelpers Pro に戻ります。手順をキャンセルした場合やコールバックが失敗した場合は、Google の手順をもう一度開始してください。
  • Apple — ブラウザでの手順を完了して XHelpers Pro に戻ります。手順をキャンセルした場合やコールバックが失敗した場合は、Apple の手順をもう一度開始してください。Hide My Email を選んだ場合、アカウント関連のメールは Apple のリレーを経由して届き、Apple ID の設定でこのリレーをオフにすると届かなくなります。

2 つのプロバイダー ID がひとりでに統合されるのは、プロバイダーが同一の確認済みメールアドレスを確認した場合だけです。別のアドレスを使用する Google または Apple の ID を追加することは、「サインイン方法を管理」で明示的に行うリンク操作です。

実際に使用できるリンク済みの方法を、少なくとも 1 つ保持してください。サポートでは、メールアドレス、表示名、レシートの画像、またはライセンスキーを知っていることを根拠に、ID、メンバーシップ、利用権、ライセンスを再割り当て、統合、復旧することはできません。

サインアウトと削除

  • サインアウト はこの Mac のセッションを消去します。サーバー上のデータ、Xin アカウント、ローカルの有効化が削除されることはありません。
  • XHelpers データを削除 は、XHelpers メンバーシップ、サーバー利用権、XHelpers のサーバーデータを削除します。Xin アカウント、他のメンバーシップ、サインイン ID、ローカルファイル、ローカルの有効化はそのまま残ります。
  • Xin アカウントをすべての場所から削除 は、アカウントに表示されているすべての製品メンバーシップ、Xin アカウント、サインイン ID を削除し、この Mac のセッションを消去します。Apple 側の認可が取り消されるわけではありません。取り消したい場合は、Apple ID の設定で Sign in with Apple から XHelpers を削除してください。ローカルライセンスは有効化されたまま残ります。
  • サインイン ID を削除 は、サインインは済んでいるが Xin アカウントを作成していない場合に該当します。

いずれの削除でも、リンク済みの方法で改めてサインインし、確認用のテキストを正確に入力する必要があります。いったん受け付けられると、取り消すことはできません。

ネットワークの問題、アプリの終了、サインアウトによって削除が中断された場合は、アカウントウインドウを開き直して続行してください。保留中の操作は同じ操作として再開されます。2 回目の削除を開始しないでください。

サポートがパスワード、サインインコード、トークン、再開用の認証情報、Keychain（キーチェーン）のエクスポートを求めることは決してありません。アカウントに関する問題については、アカウントウインドウに表示される操作識別子を送信し、それ以外の内容は下書きから削除してください。

メモ

  • XHelpers Pro は macOS メニューバーに表示され、Dock アイコンは表示しません。
  • Auto Wi-Fi Switch は、macOS が Wi-Fi ネットワーク名を保護するため、位置情報の許可が必要になる場合があります。
  • キーボードバックライト制御は Mac ハードウェアの対応状況に依存します。
  • 詳しくは XHelpers Pro プライバシーポリシー をご覧ください。
