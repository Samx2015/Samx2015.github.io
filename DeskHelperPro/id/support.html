Dukungan DeskHelper Pro

Untuk dukungan, pertanyaan privasi, bug, lisensi, atau ide, kirim email ke admin@xintechllc.com.

Anda juga dapat memakai Laporkan Bug, Sarankan Fitur, atau Kirim Masukan di menu app. Item ini membuka draf email agar dapat ditinjau sebelum dikirim.

Saat melaporkan masalah

Sertakan:

  • Apa yang terjadi dan apa yang Anda harapkan.
  • Versi macOS dan model Mac jika diketahui.
  • Apakah layar MacBook dicerminkan atau diperluas.
  • Versi dan nomor build DeskHelper Pro.
  • Langkah untuk mereproduksi masalah.

Draf laporan bug dapat menyertakan catatan diagnostik singkat. Hapus apa pun yang tidak ingin dikirim.

Menu konteks Finder

DeskHelper Pro menggunakan ekstensi Finder bawaan. macOS mengontrol apakah ekstensi aktif. Anda dapat membuka izin dari menu DeskHelper Pro atau di Pengaturan Sistem bagian Item Login dan Ekstensi.

  • Jika menu konteks Finder tidak muncul, pastikan DeskHelper Pro berjalan dari Applications.
  • Buka menu DeskHelper Pro dan pilih konfigurasi menu konteks Finder.
  • Jika tindakan Finder tidak dapat membuka atau membuat item, macOS mungkin meminta akses folder.
  • Untuk lokasi macOS terlindungi, buka Full Disk Access dari DeskHelper Pro dan aktifkan app.

Safes dan Secure Pocket

Gunakan menu konteks Finder untuk mengenkripsi file atau folder lokal terpilih menjadi file .safe, menambahkan item ke Safe yang ada, atau mendekripsi Safe ke folder. Kata sandi hanya digunakan untuk tindakan yang dimulai dan tidak disimpan oleh DeskHelper Pro.

Secure Pocket menyimpan catatan pribadi, cuplikan clipboard, dan file kecil di brankas terenkripsi lokal. DeskHelper Pro tidak mengunggah, mengirim, atau mencatat konten atau kata sandi.

Lisensi dan pembaruan

  • DeskHelper Pro menyertakan uji coba 14 hari.
  • Aktivasi lisensi menggunakan Lemon Squeezy dan menyimpan kunci di Keychain Mac.
  • Pembaruan diperiksa melalui Sparkle saat pemeriksaan otomatis aktif atau saat Anda memilih Periksa Pembaruan.

Catatan

  • DeskHelper Pro muncul di bilah menu macOS dan tidak menampilkan ikon Dock.
  • Auto Wi-Fi Switch mungkin memerlukan izin Lokasi karena macOS melindungi nama jaringan Wi-Fi.
  • Kontrol lampu keyboard bergantung pada dukungan perangkat keras Mac.
  • Baca Kebijakan Privasi DeskHelper Pro untuk detail.
