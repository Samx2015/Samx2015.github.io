Kebijakan Privasi

Tanggal berlaku: 6 Juli 2026.

Ini adalah terjemahan. Versi bahasa Inggris adalah versi yang berlaku.

XHelpers adalah utilitas bilah menu macOS lokal pertama untuk ditampilkan kontrol, tindakan menu konteks Finder, dan enkripsi Safe lokal.

  • Tidak ada proses masuk XHelpers, akun berlangganan, atau profil pengguna.
  • Tidak ada pelacakan peristiwa, pelacakan sesi, piksel iklan, atau telemetri penggunaan.
  • Tindakan tampilan, Finder, Safe, dan umpan balik dijalankan secara lokal kecuali Anda memilih untuk mengirim dukungan email.

Pengumpulan Data

XHelpers tidak mengumpulkan, menyimpan, menjual, membagikan, atau mengirimkan secara pribadi informasi melalui manajemen tampilan, tindakan Finder, atau Safe fitur enkripsi. Xintech LLC tidak menerima informasi tentang tampilan, file, pengaturan, penggunaan, atau perangkat Anda dari aplikasi kecuali Anda sengaja mengirimkannya melalui email support.

  • Tidak diperlukan akun XHelpers.
  • Tidak ada analisis, SDK pelacakan, SDK periklanan, atau SDK pelaporan kerusakan yang disertakan.
  • Tidak ada telemetri latar belakang yang dikirim ke Xintech LLC.

Data Lokal

XHelpers mungkin menyimpan sejumlah kecil data preferensi lokal dan log diagnostik lokal terbatas di Mac Anda. Ini digunakan untuk membuat aplikasi berperilaku konsisten antara peluncuran dan menyiapkan laporan bug draf ketika Anda memilih untuk melaporkan bug.

Preferensi lokal mungkin termasuk:

  • Pengaturan menu seperti pemadaman otomatis, mirroring, penyesuaian tampilan, pintasan keyboard, dan preferensi mulai saat login.
  • Preferensi menu konteks Finder, termasuk tindakan mana yang diaktifkan dan editor, terminal, atau aplikasi kompatibel mana yang Anda pilih.
  • Bookmark akses folder, preferensi alur kerja Safe, dan pesan diagnostik lokal terbatas. XHelpers tidak pernah menyimpan kata sandi Safe.

XHelpers menggunakan API tampilan macOS untuk kontrol tampilan dan macOS API ekstensi Finder untuk tindakan menu konteks Finder. Finder dan Operasi Safe membaca pilihan lokal hanya ketika Anda memilih a XHelpers tindakan, dan XHelpers tidak mengunggah jalur Finder, isi file, isi Safe, atau kata sandi Safe ke Xintech LLC.

Aktivitas Jaringan

Kontrol tampilan normal XHelpers, menu konteks Finder, dan Safe fitur enkripsi tidak memerlukan koneksi jaringan. Pembaruan adalah ditangani melalui Mac App Store.

Item menu umpan balik membuka draf di aplikasi email default Anda. Aplikasi tidak mengirim email secara otomatis, dan tidak ada yang dikirim kecuali Anda pilih Kirim.

Laporan Bug, Permintaan Fitur, dan Masukan

Opsi "Laporkan Bug...", "Sarankan Fitur...", dan "Kirim Masukan..." item menu membuka draf di aplikasi email default Anda yang dialamatkan Xintech LLC. Aplikasi tidak mengirim email secara otomatis. Anda bisa meninjau, mengedit, atau menghapus draf sebelum mengirimkannya.

Draf tersebut mungkin mencakup ringkasan diagnostik singkat sehingga dukungan dapat mencakupnya memahami konteksnya: versi aplikasi, versi macOS, prosesor arsitektur, status tampilan, status ekstensi Finder, diaktifkan tindakan, dan status aplikasi saat ini. Alamat email Anda terlihat oleh Xintech LLC hanya jika Anda mengirim email.

Draf laporan bug mungkin menyertakan kutipan terbatas dari laporan terbaru XHelpers log diagnostik. Permintaan fitur dan masukan umum draft tidak termasuk log.

Diagnostik dan Log

XHelpers menulis pesan diagnostik ke perangkat lokal terpadu Apple sistem pencatatan dan menyimpan log diagnostik aplikasi-lokal kecil yang dibatasi. Log ini disimpan secara lokal di Mac Anda. Memilih "Laporkan Bug..." dapat mengumpulkan kutipan khusus XHelpers yang dibatasi dari aplikasi-lokal log dan masukkan ke dalam draft email.

Tidak ada yang terkirim kecuali Anda memilih Kirim, dan Anda dapat menghapusnya ringkasan diagnostik atau kutipan log sebelum mengirim laporan bug.

Pilihan Anda

  • Anda dapat membiarkan draf masukan tidak terkirim, mengeditnya, atau menghapus detail diagnostik.
  • Anda dapat mengaktifkan atau menonaktifkan ekstensi Finder di pengaturan macOS.
  • Anda dapat menghapus preferensi aplikasi lokal dan persetujuan folder menggunakan alat manajemen preferensi macOS biasa.

Analitik situs web

Situs web ini menggunakan Umami Cloud, layanan analitik tanpa cookie, untuk menghitung kunjungan halaman dan tindakan dasar situs seperti klik App Store, unduhan, dukungan, privasi, ketentuan, dan tautan email. Metrik situs web ini membantu Xintech LLC memahami halaman mana yang berguna. Ini terpisah dari aplikasi itu sendiri; aplikasi tidak menyertakan SDK analitik dan tidak mengirim telemetri penggunaan aplikasi ke Xintech LLC.
