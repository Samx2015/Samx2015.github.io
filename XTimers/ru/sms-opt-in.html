XTimers по Xintech LLC SMS Сведению о согласии

Этот перевод предоставлен для удобства. Английская версия имеет приоритет. English

На этой странице документируется процесс регистрации XTimers SMS для проверки номеров с бесплатной линией. XTimers управляется Xintech LLC. Конечный бизнес, отображаемый пользователям, это XTimers, осуществляемый Xintech LLC. После того как вошедший в систему пользователь даст явное согласие, XTimers может попытаться отправить код проверки настройки на предложенный пользователем номер телефона аккаунта. После успешной проверки и согласия, созданный пользователем таймер/напоминание SMS может быть отправлено только на тот же номер телефона. XTimers не позволяет пользователям отправлять сообщения произвольным третьим лицам, не отправляет маркетинговые SMS сообщения и не предоставляет двусторонний SMS чат.

Порядок согласия

  1. Пользователь входит в систему на XTimers.
  2. Пользователь открывает информацию об учетной записи.
  3. Пользователь открывает раздел «Настроить SMS».
  4. Пользователь вводит собственный номер телефона.
  5. Флажок согласия на SMS не отмечен заранее.
  6. Пользователь явно устанавливает флажок согласия на SMS.
  7. Пользователь может открыть ссылки на Условия SMS и Политику конфиденциальности на одном и том же экране.
  8. Пользователь нажимает Продолжить, чтобы запросить одноразовый код подтверждения на предложенный номер телефона учетной записи.
  9. После того как телефон будет подтвержден и подключен к опции, пользователь может назначать напоминания SMS только на тот же подтвержденный телефонный номер, подключенный к опции.

Текст согласия

Я согласен получать коды подтверждения SMS и напоминания от XTimers по Xintech LLC, которые я запланировал сам для этого номера телефона. Могут применяться стандартные тарифы на сообщения и данные. Ответьте STOP, чтобы отказаться, и HELP для получения помощи. Частота сообщений может варьироваться. XTimers не будет отправлять рекламные сообщения. Согласие не является условием покупки.

Текущие данные согласия

Экран живой регистрации показывает точный текст согласия выше, поле для ввода номера телефона, непомеченный подтверждающий флажок, SMS ссылки на Условия и Политику конфиденциальности, формулировки STOP/HELP, раскрытие частоты сообщений и тарифов на сообщения/данные, а также область действия SMS только для владельца телефона.

Примеры форматов сообщений

Доставка для подтверждения может использовать шаблон, специфичный для провайдера или региона. Пример формата сообщения для подтверждения:

123456 — это ваш проверочный код.

Запланированное напоминание использует текст напоминания, созданного пользователем, с возможной обрезкой и форматированием провайдером доставки. Например, напоминание может содержать:

Забрать ребенка на уроки фортепиано после школы.

Инструкции по ключевым словам

Входящие ключевые слова используются только для соблюдения требований и управления сообщениями на телефонном счете. STOP отписывается, HELP запрашивает помощь, и START или YES могут вновь подключить ранее отписанный номер телефона после согласия в приложении. Обработка оператором и поставщиком может отличаться; XTimers не обещает конкретный автоматический ответ на ключевое слово. XTimers не принимает общие SMS разговоры.
